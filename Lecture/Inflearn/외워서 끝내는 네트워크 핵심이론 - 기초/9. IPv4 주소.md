# 🌐 IPv4 주소 정리

## IPv4 주소
- IPv4는 **OSI 3계층(Network Layer, Internet 계층)** 에서 사용하는 주소 체계이다.
- IPv4는 총 **32bit** 로 구성된다.
- 보통 **8bit × 4 형태로 생각하면 이해하기 쉽다.
- 각 옥텟은 **0~255 범위**의 숫자로 표현된다.

예:  
192.168.0.10

---

## Network ID와 Host ID

예를 들어 `192.168.0.10/24` 라고 가정할 때:
- 앞 24bit  
  (11000000.10101000.00000000)  
  → **Network ID**

- 뒤 8bit  
  (00001010)  
  → **Host ID**

이를 비유로 설명하면:
- Network ID = 집 주소의 "서울시 강남구 역삼동"
- Host ID = 집 주소의 "245번지"

즉,
- Network ID는 **어느 네트워크에 속하는지**
- Host ID는 **그 네트워크 안에서 어떤 장치인지**

를 의미한다.

※ 중요한 점:
Network와 Host의 구분은 고정이 아니라,
`/24` 같은 CIDR 표기(서브넷 마스크)에 의해 결정된다.
