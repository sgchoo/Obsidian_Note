# Network와 Networking

## 1. Network vs Networking

|용어|의미|핵심|
|---|---|---|
|**Network**|연결된 구조, 망|관계|
|**Networking**|네트워크를 통한 활동|상호작용|

---

## 2. 일상 속 Networking 예시

"철수"가 "Olivia"와 **상호작용(의사소통)**을 하고 싶다면?

```
┌─────────────────────────────────────────────────────┐
│  L3: 영어(언어) 문제 해결                            │
│      → 서로 이해할 수 있는 언어가 필요               │
├─────────────────────────────────────────────────────┤
│  L2: 말 또는 글(Email)로 의사소통                    │
│      → 의사소통 방식(매체) 선택                      │
├─────────────────────────────────────────────────────┤
│  L1: 말로 한다면, 공기 중 + 2m 이내 위치             │
│      → 물리적 환경 조건 충족                         │
└─────────────────────────────────────────────────────┘
```

### 2.1 Layered 구조의 의존성

- L3(언어)가 동작하려면 → L2(매체)가 필요
- L2(매체)가 동작하려면 → L1(물리적 환경)이 필요
- 각 계층은 하위 계층에 **의존**한다 → **Layered 구조**

---

## 3. Protocol (프로토콜)

> **Protocol**: 각 Layer에서 지켜야 할 **규칙**

|계층|프로토콜 (규칙)|
|---|---|
|L3|"영어로 대화한다"는 약속|
|L2|"말로 전달한다"는 약속|
|L1|"2m 이내, 공기 중"이라는 물리적 조건|

---

## 4. 개념과 구현 (Concept vs Implementation)

### 4.1 관계 정의

```
    개념 (Concept)              구현/실체 (Implementation)
   ┌───────────┐    상속      ┌───────────┐
   │   연예인   │ ◀─────────  │   박은빈   │
   └───────────┘              └───────────┘
```

- **개념 요소**: 추상적인 정의, 틀, 규격 (예: 연예인)
- **구현 요소**: 개념을 실제로 구현한 것 (예: 박은빈)
- **관계**: 구현은 개념을 **상속(구현)**한다

### 4.2 네트워크에서의 적용

위의 철수-Olivia 의사소통 모델도 **OSI 7 Layer**와 같은 **개념적 모델**이다.

|구분|개념 (Concept)|구현 (Implementation)|
|---|---|---|
|모델|OSI 7 Layer|TCP/IP 4 Layer|
|3계층|Network Layer|IP (Internet Protocol)|
|4계층|Transport Layer|TCP, UDP|
|7계층|Application Layer|HTTP, FTP, SMTP|

---

## 5. 핵심 요약

1. **Network**는 관계, **Networking**은 상호작용
2. 의사소통도 **Layered 구조**로 설명할 수 있다
3. **Protocol**은 각 계층에서 지켜야 할 규칙
4. **개념**(추상)과 **구현**(실체)은 상속 관계
5. **OSI 7 Layer**는 네트워크의 개념적 모델이다
