# L3 Packet (IP Packet) 정리

---

## 1. 개요
- **Packet은 L3(Network Layer)의 데이터 단위**
- L3에서 사용하는 패킷은 정확히 **IP Packet**
- 일반적으로 네트워크에서 “패킷”이라고 하면 IP Packet을 의미함

---

## 2. 구조

IP Packet은 다음 두 부분으로 구성된다.
### 2.1 Header
- 출발지 IP 주소
- 목적지 IP 주소
- TTL (Time To Live)
- Protocol 정보 (TCP, UDP 등)
- Total Length
- 기타 제어 정보

→ 패킷의 전달 및 제어를 위한 메타데이터 영역

### 2.2 Payload
- 실제 데이터 영역
- 일반적으로 TCP Segment 또는 UDP Datagram이 포함됨

### 2.3 계층 포함 구조

```
Frame (L2)
 └─ IP Packet (L3)
      └─ TCP/UDP Segment (L4)
           └─ Application Data (HTTP 등)
```

---

## 3. MTU (Maximum Transmission Unit)

### 3.1 정의
- 한 번에 전송 가능한 최대 L3 데이터 크기
- 이더넷 환경의 기본 MTU는 **1500 bytes**

### 3.2 MTU 초과 시
- 패킷이 여러 개로 분할됨 (Fragmentation, 단편화)
- 예: 3000 bytes 전송 시 → 1500 + 1500으로 분할

|계층|데이터 단위|
|---|---|
|L4 (Transport)|Segment|
|L3 (Network)|Packet|
|L2 (Data Link)|Frame|
|L1 (Physical)|Bit|

---

## 6. 핵심 요약

- Packet은 L3(Network Layer)의 데이터 단위이며, IP Packet을 의미한다.
    
- IP Packet은 Header와 Payload로 구성된다.
    
- 기본 MTU는 1500 bytes이다.
    
- MTU를 초과하면 Fragmentation이 발생한다.
    
- Wireshark를 통해 패킷 구조 및 내부 필드를 분석할 수 있다.
