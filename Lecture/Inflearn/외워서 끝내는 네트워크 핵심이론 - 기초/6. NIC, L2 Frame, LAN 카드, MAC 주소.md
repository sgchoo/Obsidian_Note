# Network 기초: NIC와 L2 Frame

## NIC (Network Interface Card)

### 정의 및 특징

- **NIC**는 Network Interface Card의 약자로, 일반적으로 **LAN 카드**라고 부릅니다
- 컴퓨터와 네트워크를 물리적으로 연결하는 **하드웨어(H/W)** 장치입니다

### 유형

- **유선 NIC**: 이더넷 케이블을 통해 연결
- **무선 NIC**: Wi-Fi를 통해 연결
- 실무에서는 유선/무선을 엄격히 구분하지 않고 통칭하여 NIC라고 표현합니다

### MAC 주소

- 각 NIC는 고유한 **MAC 주소(Media Access Control Address)**를 가집니다
- MAC 주소는 48비트(6바이트) 길이의 물리적 주소입니다
- 제조사에서 할당하는 전 세계적으로 고유한 식별자입니다

### 노드와 NIC의 관계

- 하나의 **노드(Node)**는 **1개 이상의 NIC**를 가질 수 있습니다
- 예시:
    - 서버: 유선 NIC 여러 개 (네트워크 이중화, 대역폭 확장)
    - 노트북: 유선 NIC 1개 + 무선 NIC 1개
    - 데스크톱: 유선 NIC 1개

## L2 Frame

### 정의

- **L2 Frame**은 OSI 7계층 중 **데이터 링크 계층(Layer 2)**에서 사용되는 데이터 전송 단위입니다
- 네트워크에서 실제로 데이터가 유통되는 기본 형태입니다

### 전송 속도 표기

- 네트워크 속도는 주로 **bps(bits per second)** 단위로 표기됩니다
- 일반적인 표기 예시:
    - **1Gbps** (Gigabit per second): 초당 10억 비트 전송
    - **100Mbps**: 초당 1억 비트 전송
    - **10Gbps**: 초당 100억 비트 전송

### L2 Frame 구조 (참고)

```
┌──────────────┬──────────────┬──────┬─────────┬─────┐
│ Destination  │   Source     │ Type │ Payload │ FCS │
│ MAC Address  │ MAC Address  │      │ (Data)  │     │
└──────────────┴──────────────┴──────┴─────────┴─────┘
```

- **Destination MAC**: 목적지 MAC 주소
- **Source MAC**: 출발지 MAC 주소
- **Type**: 상위 프로토콜 정보
- **Payload**: 실제 데이터
- **FCS (Frame Check Sequence)**: 오류 검출용

## 요약

|항목|설명|
|---|---|
|NIC|네트워크 연결을 위한 하드웨어, MAC 주소 보유|
|MAC 주소|NIC의 고유 물리적 식별자|
|L2 Frame|데이터 링크 계층의 데이터 전송 단위|
|전송 속도|bps 단위로 표기 (예: 1Gbps)|
