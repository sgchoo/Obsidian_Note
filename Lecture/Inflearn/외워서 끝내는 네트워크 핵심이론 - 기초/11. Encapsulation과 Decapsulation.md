# Encapsulation & Decapsulation 정리

---

## 1. 개요

Encapsulation과 Decapsulation은  
**OSI 계층 구조에서 데이터가 전달되는 과정**을 설명하는 핵심 개념이다.

데이터는 전송 과정에서 계층별로 포장(Encapsulation)되며,  
수신 측에서는 반대로 포장이 벗겨진다(Decapsulation).

---

## 2. Encapsulation (캡슐화)

### 2.1 정의
- 상위 계층의 데이터를 하위 계층이 감싸는 과정
- 각 계층에서 자신의 **Header(또는 Trailer)** 를 추가하여 단위화함
- 데이터를 전송 가능한 형태로 “포장”하는 과정

### 2.2 비유
- **마트료시카 인형 구조**
    - 작은 인형이 큰 인형 안에 들어가듯,
    - 상위 계층 데이터가 하위 계층 안에 포함됨

### 2.3 과정 흐름 (송신 측)

```
Application Data
  ↓
L4: Segment 생성 (TCP/UDP Header 추가)
  ↓
L3: Packet 생성 (IP Header 추가)
  ↓
L2: Frame 생성 (MAC Header + Trailer 추가)
  ↓
L1: Bit 단위로 전송
```

→ 각 계층은 자신의 제어 정보를 추가하여 하나의 전송 단위로 만든다.

### 2.4 목적
- 계층별 역할 분리
- 독립적 설계 가능
- 데이터 전달 경로 및 방식 제어

---

## 3. Decapsulation (디캡슐화)

### 3.1 정의

- 수신 측에서 하위 계층부터 Header를 제거하는 과정
- 포장된 데이터를 벗겨내는 과정

### 3.2 과정 흐름 (수신 측)

```
Bit 수신
  ↓
L2: Frame Header 제거
  ↓
L3: IP Header 제거
  ↓
L4: TCP/UDP Header 제거
  ↓
Application Data 전달
```

→ 각 계층은 자신의 Header를 확인한 뒤 제거하고 상위 계층으로 전달한다.

---

## 4. 전체 구조 요약
### 송신 측 (Encapsulation)

```
Data → Segment → Packet → Frame → Bit
```

### 수신 측 (Decapsulation)

```
Bit → Frame → Packet → Segment → Data
```

---

## 5. 핵심 개념 정리
- **Encapsulation**: 계층별 Header를 추가하여 데이터를 포장하는 과정
- **Decapsulation**: 수신 시 계층별 Header를 제거하는 과정
- 데이터는 송신 시 위에서 아래로, 수신 시 아래에서 위로 이동한다.
- 계층 구조 설계의 핵심 동작 원리이다.
