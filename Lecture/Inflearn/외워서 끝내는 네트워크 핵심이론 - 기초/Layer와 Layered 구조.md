# 네트워크 Layer와 Layered 구조

## 1. 설계(Design)란?

**설계**란 목표를 달성하기 위한 **요소(Element)**와 **관계(Relationship)**를 구상하는 것이다.

- **요소**: 시스템을 구성하는 개별 단위 (예: 모듈, 컴포넌트, 계층 등)
- **관계**: 요소들 간의 상호작용 방식 (예: 호출, 의존, 통신 등)

좋은 설계는 복잡한 시스템을 이해하기 쉽고, 유지보수하기 편하며, 확장 가능하게 만든다.

---

## 2. Layered 구조 (계층 구조)

### 2.1 정의

**Layered 구조**는 시스템을 여러 계층(Layer)으로 분리하여 구성하는 설계 방식이다.

### 2.2 핵심 특징: 의존성(Dependency)

- 상위 계층은 **바로 아래 하위 계층에만 의존**한다
- 하위 계층은 상위 계층을 알지 못한다 (단방향 의존)
- 각 계층의 **존립 자체가 하위 계층에 의존**한다

```
┌─────────────────────┐
│   상위 계층 (N+1)    │  ← 하위 계층의 서비스를 이용
├─────────────────────┤
│   현재 계층 (N)      │  ← 상위에게 서비스 제공, 하위 서비스 이용
├─────────────────────┤
│   하위 계층 (N-1)    │  ← 상위에게 서비스 제공
└─────────────────────┘
```

### 2.3 Layered 구조의 장점

|장점|설명|
|---|---|
|**모듈화**|각 계층이 독립적인 기능 단위로 분리됨|
|**캡슐화**|하위 계층의 구현 세부사항을 상위 계층에서 숨김|
|**유지보수 용이**|특정 계층만 수정해도 다른 계층에 영향 최소화|
|**재사용성**|각 계층을 독립적으로 재사용 가능|
|**표준화**|계층 간 인터페이스를 표준화하여 호환성 확보|

## 3. OSI 7 Layer 모델

Layered 구조의 대표적인 예가 **OSI(Open Systems Interconnection) 7 Layer** 모델이다.

### 3.1 계층 구성

|계층|이름|주요 기능|프로토콜/장비 예시|
|:-:|---|---|---|
|**7**|응용 계층 (Application)|사용자와 직접 상호작용하는 서비스|HTTP, FTP, SMTP, DNS|
|**6**|표현 계층 (Presentation)|데이터 형식 변환, 암호화, 압축|JPEG, MPEG, SSL/TLS|
|**5**|세션 계층 (Session)|연결 설정, 유지, 종료 관리|NetBIOS, RPC|
|**4**|전송 계층 (Transport)|종단 간 신뢰성 있는 데이터 전송|TCP, UDP|
|**3**|네트워크 계층 (Network)|논리적 주소 지정, 경로 설정|IP, ICMP, Router|
|**2**|데이터링크 계층 (Data Link)|물리적 주소 지정, 프레임 전송|Ethernet, MAC, Switch|
|**1**|물리 계층 (Physical)|비트 단위의 전기적 신호 전송|Cable, Hub, NIC|

### 3.2 데이터 캡슐화 과정

데이터가 송신 측에서 하위 계층으로 내려가면서 각 계층의 헤더가 추가된다.

```
[Application Data]
       ↓ 캡슐화
[L4 Header][Data]                    → Segment
       ↓
[L3 Header][L4 Header][Data]         → Packet
       ↓
[L2 Header][L3][L4][Data][L2 Trailer] → Frame
       ↓
[비트 스트림]                          → Bits
```

### 3.3 의존성 관계 예시

- **HTTP(7계층)**는 **TCP(4계층)** 없이는 데이터를 전송할 수 없다
- **TCP(4계층)**는 **IP(3계층)** 없이는 목적지를 찾을 수 없다
- **IP(3계층)**는 **Ethernet(2계층)** 없이는 실제 전송이 불가능하다

→ 각 상위 계층의 존립이 하위 계층에 **의존**한다

---

## 4. 핵심 요약

1. **설계**는 요소와 관계를 구상하는 것
2. **Layered 구조**는 상위 계층이 하위 계층에 의존하는 구조
3. **OSI 7 Layer**는 네트워크 통신을 7개의 계층으로 분리한 표준 모델
4. 계층화를 통해 **복잡도 감소**, **모듈화**, **표준화**의 이점을 얻을 수 있다
