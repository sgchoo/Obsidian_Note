# Port / IP / MAC 역할 정리

네트워크에서 데이터는 **어떤 프로세스 → 어떤 컴퓨터 → 어떤 장치** 순서로 전달된다.

각 계층은 서로 다른 대상을 식별한다.

| 계층 | 식별 대상 | 사용 주소 |
|-----|-----------|----------|
| L4 (Transport) | Process | Port |
| L3 (Network) | Host | IP Address |
| L2 (DataLink) | Network Interface | MAC Address |

---

# 1. Port (프로세스 식별)

Port는 **Host 내부에서 어떤 Process와 통신할 것인지 식별하는 번호**이다.

예시

```

웹 서버 → 80  
HTTPS → 443  
MySQL → 3306

```


즉 같은 컴퓨터 안에서도 여러 서비스가 동시에 동작할 수 있도록 구분한다.

```

Host  
├ Web Server (Port 80)  
├ DB Server (Port 3306)  
└ SSH Server (Port 22)

```

---

# 2. IP Address (Host 식별)

IP 주소는 **네트워크에서 어떤 Host(컴퓨터)로 데이터를 보낼지 결정한다.**

예시

```

192.168.0.10  
172.16.0.5  
8.8.8.8

```

즉

> 네트워크 상에서 **어느 컴퓨터인지 식별하는 주소**

---

# 3. MAC Address (장치 식별)

MAC Address는 **같은 네트워크(LAN)에서 어떤 장치에게 데이터를 전달할지 결정한다.**

예시

```

00:1A:2B:3C:4D:5E

```

MAC 주소는 **Network Interface Card(NIC)** 에 부여된 물리 주소이다.

즉

> 같은 네트워크 내부에서 **어떤 장치인지 식별하는 주소**

---

# 4. 실제 데이터 전달 흐름

예를 들어

```

내 브라우저 → 구글 서버

```

데이터는 다음 순서로 전달된다.

```

Port → Process  
IP → Host  
MAC → Network Device

```

즉

```

MAC : 어떤 장치로 갈까?  
IP : 어떤 컴퓨터로 갈까?  
Port : 어떤 프로그램으로 갈까?

```

---

# 핵심 3줄 정리

MAC Address → 같은 네트워크에서 장치를 식별  
IP Address → 네트워크에서 Host를 식별  
Port → Host 내부에서 Process를 식별
