# 📡 LAN과 WAN, Broadcast 그리고 OSI 7계층 정리

---

## 1️⃣ LAN과 WAN의 경계

### 🔹 LAN (Local Area Network)
- 물리적으로 연결된 네트워크 범위
- 같은 스위치/허브에 연결된 네트워크
- 보통 **Physical 영역 (1~2계층)** 중심

### 🔹 WAN (Wide Area Network)
- 서로 다른 네트워크를 연결하는 광역 네트워크
- 인터넷을 통한 통신
- 보통 **Logical 영역 (3~7계층)** 중심

---

## 2️⃣ Broadcast의 개념

### 🔹 Broadcast란?
- 네트워크에 **연결된 모든 장치에게 동시에 데이터를 전송하는 방식**

### 🔹 Broadcast 주소
Broadcast에는 특별한 주소가 존재한다.

|종류|주소|
|---|---|
|MAC Broadcast|`ff-ff-ff-ff-ff-ff`|
|IP Broadcast|네트워크의 마지막 주소 (예: 192.168.0.255 등)|

### 🔹 Broadcast 범위
- Broadcast 범위는 **연결되어 있는 모든 네트워크**
- 같은 LAN 내부에서는 전체 장비가 수신함
- 라우터를 넘으면 기본적으로 Broadcast는 전달되지 않음

### 🔹 Broadcast를 최소화해야 하는 이유
- 모든 장비가 데이터를 처리해야 함
- 네트워크 트래픽 증가
- 성능 저하 가능성

👉 따라서 **Broadcast Domain을 작게 유지하는 것이 중요**

## 3️⃣ OSI 7계층에서의 LAN과 WAN

### 🔹 OSI 계층 구분

|계층|설명|성격|
|---|---|---|
|1계층|Physical (물리 계층)|H/W|
|2계층|Data Link (Ethernet)|H/W|
|3계층|Network (IP)|S/W|
|4계층|Transport (TCP/UDP)|S/W|
|5~7계층|Session, Presentation, Application|S/W|

---

## 4️⃣ Physical vs Logical 개념

### 🔹 Physical (물리적)
- 1~2계층
- 실제 케이블, 전기 신호, MAC 주소 기반 통신
- Ethernet 통신
- **LAN 통신과 밀접한 관계**

👉 여기서 오는 신호는 물리적 신호라 칭함

---

### 🔹 Logical (논리적)
- 3~7계층
- IP 주소 기반 통신
- 소프트웨어적 개념
- 가상 네트워크
- **WAN 통신과 밀접한 관계**

👉 Internet에서 오는 신호는 논리적 신호라 칭함

---

## 5️⃣ Logical = Virtual 개념

- Logical은 Virtual이라고도 부름
- 논리적 네트워크 = 가상 네트워크
- H/W를 S/W로 구현한 것 → Virtual Machine

### 예시
- VLAN (가상 LAN)
- VPN (가상 사설망)
- Virtual Machine (소프트웨어로 구현한 가상 하드웨어)

---

## 6️⃣ 정리 요약

- Broadcast는 연결된 모든 네트워크로 전파됨
- MAC Broadcast 주소는 `ff-ff-ff-ff-ff-ff`
- Broadcast 범위는 최소화해야 함
- 1~2계층은 Physical (LAN 중심)
- 3~7계층은 Logical (WAN 중심)
- Logical은 Virtual 개념과 연결됨
- Physical은 실제 신호 기반 통신
