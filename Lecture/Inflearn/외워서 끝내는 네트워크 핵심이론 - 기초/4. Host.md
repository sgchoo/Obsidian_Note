# Network Host 개념 정리

## Host의 정의

Host는 네트워크에 연결된 컴퓨팅 장치를 의미하며, 다음 두 요소의 결합으로 정의할 수 있습니다:

```
Host = Computer + Network
```

- **Computer**: 연산 및 데이터 처리 능력을 가진 장치
- **Network**: 다른 장치와 통신할 수 있는 네트워크 인터페이스 및 프로토콜 스택

## Host의 분류

Host는 네트워크에서의 역할에 따라 크게 두 가지 유형으로 분류됩니다:

### 1. End-Point (종단점)

네트워크 인프라를 **이용하는** 주체로, 실제 데이터의 생성자 또는 최종 소비자 역할을 수행합니다.

**주요 유형:**

- **Client**: 서비스를 요청하는 호스트 (예: 웹 브라우저, 모바일 앱)
- **Server**: 서비스를 제공하는 호스트 (예: 웹 서버, 데이터베이스 서버)
- **Peer**: P2P 네트워크에서 클라이언트와 서버 역할을 동시에 수행하는 호스트

**특징:**

- 데이터의 송신자(Source) 또는 수신자(Destination)
- 응용 계층(Application Layer)에서 동작하는 프로그램 실행
- IP 주소를 가지며, 네트워크 통신의 시작점 또는 종착점

### 2. Switch (스위치)

네트워크 인프라 **그 자체를 구성하는** 주체로, 데이터를 중계하고 전달하는 역할을 수행합니다.

**주요 유형:**

- **Router (라우터)**:
    
    - 서로 다른 네트워크 간의 데이터 패킷 전달
    - IP 계층(Network Layer)에서 동작
    - 경로 선택(Routing) 기능 수행
- **L2 Switch (Layer 2 스위치)**:
    
    - 같은 네트워크 내에서 MAC 주소 기반 프레임 전달
    - 데이터 링크 계층(Data Link Layer)에서 동작
- **IPS (Intrusion Prevention System)**:
    
    - 네트워크 트래픽 모니터링 및 보안 위협 차단
    - 패킷 검사 및 필터링 수행
- **Firewall (방화벽)**:
    
    - 네트워크 접근 제어 및 트래픽 필터링
    - 보안 정책 기반 패킷 허용/차단

**특징:**

- 데이터의 중계자(Intermediary) 역할
- 네트워크 인프라스트럭�처의 핵심 구성 요소
- 패킷/프레임을 수신하여 적절한 경로로 전달
- 일반적으로 여러 개의 네트워크 인터페이스 보유

## 네트워크 통신의 흐름

일반적인 네트워크 통신은 다음과 같은 흐름으로 이루어집니다:

```
End-Point(Client) 
    → Switch(Router/Switch) 
    → Switch(Router/Switch) 
    → End-Point(Server)
```

- **End-Point**: 통신의 시작점과 종착점
- **Switch**: 경로상의 중계 장치들로 구성된 인프라

## 핵심 개념 요약

| 구분         | End-Point            | Switch                     |
| ---------- | -------------------- | -------------------------- |
| **역할**     | 네트워크 이용자             | 네트워크 구성자                   |
| **기능**     | 데이터 생성/소비            | 데이터 중계/전달                  |
| **위치**     | 네트워크의 가장자리(Edge)     | 네트워크의 중심(Core)             |
| **예시**     | PC, 스마트폰, 서버         | 라우터, 스위치, 방화벽              |
| **OSI 계층** | 주로 Application Layer | 주로 Network/Data Link Layer |

## 참고 사항

- 실제 환경에서는 하나의 물리적 장치가 여러 역할을 동시에 수행할 수 있습니다
    - 예: 공유기는 Router + L2 Switch + Firewall 기능을 통합
- 서버는 End-Point이지만, 데이터센터 내부에서는 인프라의 일부로 볼 수도 있습니다
- 클라우드 환경에서는 가상 스위치(Virtual Switch) 개념도 중요합니다
