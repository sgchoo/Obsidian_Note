# L2 스위치 개요

## L2 스위치란?

L2 스위치(Layer 2 Switch)는 OSI 7계층 모델의 데이터 링크 계층(Layer 2)에서 동작하는 네트워크 장비입니다. 주요 특징은 다음과 같습니다:

- **End Point 직접 연결**: PC, 프린터, 서버 등의 최종 단말 장치와 직접 연결됩니다.
- **MAC 주소 기반 스위칭**: 48비트 MAC(Media Access Control) 주소를 근거로 프레임을 전달합니다.
- **프레임 전달 방식**: MAC 주소 테이블(CAM Table)을 참조하여 목적지 포트로 프레임을 스위칭합니다.

---

## L2 스위치 하드웨어 구성 요소

### 포트(Port) / 인터페이스(Interface)

- **정의**: 네트워크 케이블을 연결하는 물리적 접속 단자
- **명명**: 각 포트는 고유한 번호로 식별됩니다 (예: Fa0/1, Gi1/0/1)

### 링크 상태

#### Link-Up

- **의미**: 물리적 연결이 정상적으로 확립된 상태
- **표시**: 포트 LED가 녹색으로 점등
- **조건**:
    - 케이블이 정상적으로 연결됨
    - 양측 장비의 물리적 계층 협상 성공
    - 전기적 신호 정상 수신

#### Link-Down

- **의미**: 물리적 연결이 끊어진 상태
- **표시**: 포트 LED 소등 또는 주황색 점등
- **원인**:
    - 케이블 미연결 또는 불량
    - 상대 장비 전원 꺼짐
    - 포트 비활성화 상태

### 업링크(Uplink)

- **정의**: L2 스위치에서 상위 계층 장비(라우터, L3 스위치 등)로 연결되는 포트
- **특징**:
    - 일반적으로 더 높은 대역폭 제공 (1Gbps, 10Gbps 등)
    - 여러 VLAN 트래픽을 전달하는 트런크(Trunk) 포트로 구성되는 경우가 많음
    - 네트워크의 병목 지점이 될 수 있어 대역폭 설계가 중요

## L2 스위치 유형

### L2 Access 스위치

- **역할**: 최종 단말 장치를 네트워크에 연결하는 엣지(Edge) 스위치
- **배치**: 네트워크 계층 구조의 최하단
- **특징**:
    - 포트 밀도가 높음 (24포트, 48포트 등)
    - 상대적으로 저렴한 비용
    - 기본적인 L2 기능 제공

### L2 Distribution 스위치

- **역할**: 여러 L2 Access 스위치를 집약(Aggregation)하는 중간 계층 스위치
- **배치**: Access 계층과 Core 계층 사이에 위치
- **주요 기능**:

#### VLAN (Virtual LAN) 지원

- **목적**: 물리적 네트워크를 논리적으로 분할하여 브로드캐스트 도메인 격리
- **이점**:
    - 보안 강화 (부서별, 용도별 네트워크 분리)
    - 브로드캐스트 트래픽 제어
    - 네트워크 관리 효율성 향상

#### 추가 기능

- **트래픽 집약**: 다수의 Access 스위치 트래픽을 상위로 전달
- **QoS (Quality of Service)**: 트래픽 우선순위 관리
- **링크 이중화**: STP, LACP 등을 통한 고가용성 제공
- **보안 기능**: ACL, 포트 시큐리티 등

## 네트워크 계층 구조에서의 위치

```
[Core Layer]
     ↑
     | (고속 백본)
     ↓
[Distribution Layer] ← L2 Distribution 스위치
     ↑
     | (Uplink)
     ↓
[Access Layer] ← L2 Access 스위치
     ↑
     | (Edge Connection)
     ↓
[End Devices] ← PC, 프린터, IP폰 등
```

## 주요 동작 원리

### MAC 주소 학습 (Learning)

1. 프레임 수신 시 출발지 MAC 주소를 MAC 주소 테이블에 저장
2. 해당 MAC 주소가 들어온 포트 번호와 매핑

### 프레임 전달 (Forwarding)

1. 목적지 MAC 주소를 MAC 주소 테이블에서 검색
2. 해당 포트로만 프레임 전달 (유니캐스트)

### 플러딩 (Flooding)

- MAC 주소 테이블에 목적지 주소가 없을 경우
- 수신 포트를 제외한 모든 포트로 프레임 전송

### 필터링 (Filtering)

- 출발지와 목적지가 같은 세그먼트에 있을 경우
- 다른 포트로 프레임을 전달하지 않음

---

## 참고사항

- L2 스위치는 IP 주소를 이해하지 못하며, 오직 MAC 주소만을 기반으로 동작합니다.
- L3 기능이 필요한 경우 L3 스위치 또는 라우터를 사용해야 합니다.
- 최신 Distribution 스위치는 L2/L3 혼합 기능을 제공하는 경우가 많습니다.
