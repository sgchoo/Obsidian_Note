# 📡 LAN, VLAN, Broadcast, ARP, L2/L3 개념 정리

---

# 1️⃣ LAN과 WAN의 본질

## ✅ LAN (Local Area Network)

- “Local”은 거리/범위 개념
    
- 반드시 물리적인 것만을 의미하지는 않음
    
- 실제 의미: **하나의 Broadcast Domain**
    

## ✅ WAN (Wide Area Network)

- 광역 네트워크
    
- 여러 LAN을 연결하는 개념
    

---

# 2️⃣ Physical vs Logical

|구분|의미|계층|
|---|---|---|
|Physical|물리 신호 기반 통신|1~2계층|
|Logical|IP 기반 논리 통신|3~7계층|

중요한 점:

> LAN/WAN은 범위 개념  
> Physical/Logical은 계층 개념  
> 둘은 동일한 축이 아니다.

---

# 3️⃣ Broadcast란?

- 목적지 MAC이 `ff:ff:ff:ff:ff:ff`
    
- 같은 Broadcast Domain 내 모든 장비가 수신
    
- ARP, DHCP 등이 대표적
    

### 🔥 Broadcast 범위

- L2 스위치만 있으면 → 전체 네트워크로 확산
    
- VLAN이 다르면 → VLAN 내부로 제한
    
- 라우터/L3 장비 → Broadcast 차단
    

---

# 4️⃣ VLAN이란?

> VLAN = Virtual LAN  
> 2계층 Broadcast Domain을 논리적으로 분리하는 기술

### 핵심 특징

- 물리적 스위치는 하나
    
- 논리적 LAN은 여러 개 가능
    
- VLAN 단위로 Broadcast 격리
    

### 예시

VLAN10 → PC1, PC2  
VLAN20 → PC3

PC1이 Broadcast하면:

- PC2는 받음
    
- PC3는 못 받음
    

---

# 5️⃣ VLAN과 IP 대역 관계

⚠️ 매우 중요한 개념

VLAN이 다르면:

- IP 대역도 달라야 한다.
    

왜냐하면:

- IP가 같으면 같은 네트워크라고 판단
    
- ARP Broadcast를 시도
    
- VLAN이 다르면 ARP가 전달되지 않음
    
- 통신 실패
    

---

# 6️⃣ ARP란?

> ARP = Address Resolution Protocol  
> IP → MAC 주소 변환 프로토콜

### 통신 흐름

1. 목적지가 같은 네트워크인지 확인
    
2. MAC 주소가 필요함
    
3. ARP Broadcast 전송
    
4. 응답 받음
    
5. MAC 기반 통신 시작
    

### 핵심

> IP 통신을 하려면 반드시 MAC 주소가 필요하다.

---

# 7️⃣ VLAN이 다르면 왜 통신이 안 될까?

VLAN이 다르면:

- 2계층이 단절됨
    
- ARP Broadcast가 전달되지 않음
    
- MAC 주소를 모름
    
- 통신 불가
    

---

# 8️⃣ VLAN 간 통신 방법

VLAN이 다르면 반드시 필요:

- 라우터
    
- 또는 L3 스위치
    

### L3 스위치란?

> L2 스위치 + 라우터 기능을 가진 장비

각 VLAN에 IP 인터페이스를 만들어  
Default Gateway 역할을 수행한다.

---

# 9️⃣ L2 vs L3 차이

|장비|Broadcast 전달|라우팅 가능|
|---|---|---|
|L2 스위치|O|X|
|라우터|X|O|
|L3 스위치|X|O|

---

# 🔟 Broadcast 범위를 줄이는 방법

Broadcast 최소화 방법은 두 가지:

## ① VLAN으로 분리 (2계층 분리)

- Broadcast Domain 나누기
    

## ② L3 장비로 경계 만들기 (3계층 분리)

- Broadcast 차단
    
- VLAN 간 연결 담당
    

실무에서는 보통:

> VLAN으로 나누고  
> L3 스위치로 연결한다.

---

# 🔥 핵심 개념 정리 (진짜 중요)

- LAN은 물리적 개념이 아니라 Broadcast Domain 개념
    
- VLAN은 2계층을 논리적으로 나누는 기술
    
- IP 통신은 반드시 MAC이 필요
    
- ARP는 IP → MAC 변환 프로토콜
    
- VLAN이 다르면 IP도 다르게 설계해야 함
    
- L3 장비가 VLAN 간 통신을 담당
    
- Broadcast는 L2까지만 유효
    

---

# 🎯 전체 구조 한 줄 요약

> L2는 같은 LAN 안에서 MAC으로 전달하고  
> L3는 서로 다른 LAN을 IP로 연결한다.
