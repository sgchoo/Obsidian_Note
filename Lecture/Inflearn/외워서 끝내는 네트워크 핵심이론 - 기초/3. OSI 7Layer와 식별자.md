# OSI 7 Layer와 식별자

## 1. 계층별 식별자 개요

각 계층은 고유한 **식별자(Identifier)**를 사용하여 통신 대상을 구분한다.

|계층|식별자|식별 대상|
|:-:|---|---|
|**L2**|MAC 주소|이더넷, PC (물리적 장치)|
|**L3**|IP 주소|호스트 (네트워크 상의 장치)|
|**L4**|Port 번호|인터페이스 / 서비스 / 프로세스|

---

## 2. L2 식별자: MAC 주소

### 2.1 정의

- **MAC (Media Access Control) 주소**
- 네트워크 인터페이스 카드(NIC)에 부여된 **물리적 주소**

### 2.2 특징

```
예시: 00:1A:2B:3C:4D:5E
      ├──────┤├──────┤
       OUI     고유번호
      (제조사)  (장치)
```

- 48비트 (6바이트), 16진수로 표기
- 앞 24비트: OUI (제조사 식별)
- 뒤 24비트: 제조사가 부여한 고유 번호
- **이더넷** 환경에서 **PC(장치)**를 식별

---

## 3. L3 식별자: IP 주소

### 3.1 정의

- **IP (Internet Protocol) 주소**
- 네트워크 상에서 **호스트(Host)**를 식별하는 **논리적 주소**

### 3.2 특징

```
IPv4 예시: 192.168.0.1
IPv6 예시: 2001:0db8:85a3:0000:0000:8a2e:0370:7334
```

- IPv4: 32비트, 약 43억 개 주소
- IPv6: 128비트, 사실상 무한한 주소
- 네트워크를 통해 **접근할 호스트**를 식별

---

## 4. L4 식별자: Port 번호

### 4.1 정의

- **Port 번호**: 0 ~ 65535 범위의 숫자
- 하나의 호스트 내에서 **여러 통신**을 구분

### 4.2 관점에 따른 해석

Port 번호는 보는 관점에 따라 다르게 해석할 수 있다:

| 관점        | 식별 대상             | 설명                                   |
| --------- | ----------------- | ------------------------------------ |
| **L2 관점** | 인터페이스 (Interface) | 데이터가 드나드는 접점                         |
| **L3 관점** | 서비스 (Service)     | 어떤 서비스에 접근하는지 (HTTP: 80, HTTPS: 443) |
| **L4 관점** | 프로세스 (Process)    | 어떤 프로세스가 통신하는지                       |

### 4.3 Port 번호 분류

|범위|분류|설명|
|---|---|---|
|0 ~ 1023|Well-known Ports|표준 서비스 (HTTP, FTP, SSH 등)|
|1024 ~ 49151|Registered Ports|등록된 애플리케이션|
|49152 ~ 65535|Dynamic/Private Ports|임시 할당용|

### 4.4 자주 사용하는 Well-known Ports

|Port|서비스|프로토콜|
|:-:|---|---|
|20, 21|FTP|TCP|
|22|SSH|TCP|
|23|Telnet|TCP|
|80|HTTP|TCP|
|443|HTTPS|TCP|
|53|DNS|TCP/UDP|
|3306|MySQL|TCP|

---

## 5. 계층별 식별자 관계

```
┌─────────────────────────────────────────────────────────┐
│  L4: Port 번호                                          │
│      → 프로세스/서비스 식별                              │
│      → "어떤 애플리케이션인가?"                          │
├─────────────────────────────────────────────────────────┤
│  L3: IP 주소                                            │
│      → 호스트 식별                                       │
│      → "어떤 컴퓨터인가?"                                │
├─────────────────────────────────────────────────────────┤
│  L2: MAC 주소                                           │
│      → 물리적 장치 식별                                  │
│      → "어떤 네트워크 카드인가?"                         │
└─────────────────────────────────────────────────────────┘
```

### 5.1 통신 시 식별자 조합

하나의 통신을 완전히 식별하려면 **5-Tuple**이 필요하다:

```
< 출발지 IP, 출발지 Port, 목적지 IP, 목적지 Port, 프로토콜 >
```

---

## 6. 핵심 요약

1. **L2 (MAC 주소)**: 물리적 장치(NIC) 식별 - "어떤 장치인가?"
2. **L3 (IP 주소)**: 논리적 호스트 식별 - "어떤 컴퓨터인가?"
3. **L4 (Port 번호)**: 프로세스/서비스 식별 - "어떤 프로그램인가?"
4. Port 번호는 관점에 따라 **인터페이스, 서비스, 프로세스**로 해석 가능
5. 완전한 통신 식별에는 **5-Tuple**이 필요
