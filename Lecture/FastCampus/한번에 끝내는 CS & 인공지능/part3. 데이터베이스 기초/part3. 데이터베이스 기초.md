# 데이터베이스 기본 개념

## 데이터와 정보

### 데이터 (Data)

- 현실에서 관찰하거나 습득한 사실이나 값
- 가공되지 않은 원시 자료

### 정보 (Information)

- 데이터를 어떤 방법으로 처리해서 의미를 가지는 단위로 처리한 것

### 정보처리 (Information Processing)

- 데이터에서 정보를 추출하는 과정 또는 방법

## 데이터의 분류

### 정량적 데이터 (정형 데이터)

- 도형, 수치, 기호 등으로 수치화할 수 있는 데이터
- 구조화되어 있어 분석이 용이함

### 정성적 데이터 (비정형 데이터)

- 언어, 소리, 문자 등의 비정형 데이터
- 구조화되지 않아 처리가 복잡함

## 정보 시스템과 데이터베이스

### 정보 시스템 (Information System)

- 조직 운영에 필요한 데이터를 수집하여 저장해두었다가, 필요할 때 정보로 가공하는 시스템

### 데이터베이스 시스템 (Database System)

- 정보 시스템 안에서 데이터를 저장하고 있다가 필요할 때, 데이터를 전달하는 역할

## 데이터베이스의 정의

- 논리적으로 연관된 데이터를 모아 일정한 형태로 저장해 놓은 것
- 중복 데이터를 최소화하여 조직의 목적에 맞게 관리하는 것

### ISOS - 데이터베이스의 4가지 특성

1. **통합된 데이터 (Integrated Data)**
    
    - 데이터 중복을 최소화한 데이터
2. **저장된 데이터 (Stored Data)**
    
    - 컴퓨터가 접근할 수 있는 저장 매체에 저장된 데이터
3. **운영 데이터 (Operational Data)**
    
    - 조직의 고유한 업무를 수행하는데 반드시 필요한 데이터
4. **공용 데이터 (Shared Data)**
    
    - 여러 응용 시스템이 공동으로 소유하고 유지하는 데이터

## 데이터베이스 시스템의 특징

### R1C3 - 데이터베이스 시스템의 4가지 특징

1. **실시간 접근성 (Real Time Accessibility)**
    
    - 사용자의 요구에 대해 실시간으로 응답
2. **지속적인 변화 (Continuous Evolution)**
    
    - 새로운 데이터의 삽입, 삭제, 갱신을 통해 항상 최신 정보 유지
3. **동시 공유 (Concurrent Sharing)**
    
    - 여러 사용자가 동시에 같은 데이터를 공유하여 사용
4. **내용에 의한 참조 (Content Reference)**
    
    - 사용자가 요구하는 데이터 내용으로 해당 데이터 참조
