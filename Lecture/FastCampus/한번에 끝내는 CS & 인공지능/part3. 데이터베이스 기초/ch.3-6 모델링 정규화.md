# 데이터베이스 정규화

## 정규화란?

다양한 유형의 검사를 통해 데이터 모델을 좀 더 구조화하고 개선시켜 나가는 절차에 관련된 이론입니다.

- **기본 원칙**: 하나의 테이블에는 중복된 데이터가 없도록 하는 것
- **제안자**: 1972년 E.F. Codd 박사에 의해 제안
- **목적**: 데이터를 수학적인 방법에 의해 구조화시켜 체계적으로 관리

## 정규화의 특징

1. **단계적 분석 방법**
    
    - 적절한 엔티티 타입에 각각의 속성들을 배치
    - 엔티티 타입을 충분히 도출해가는 단계적인 분석 방법
2. **종속 관계 활용**
    
    - 엔티티 타입에 속성들이 상호 종속적인 관계를 갖는 것을 배경으로 함
    - 종속 관계를 이용하여 엔티티 타입을 정제하는 방법
3. **데이터 분석 방법**
    
    - 각각의 속성들이 데이터 모델에 포함될 수 있는 정규화의 원리를 이용
    - 데이터를 체계적으로 분석하는 방법

## 정규화 종류

> **참고**: 3차 정규화까지 자주 사용되며, 그 이후는 특이 케이스에만 적용됩니다.

### 1차 정규화 (1NF)

- **목적**: 복수의 속성값을 갖는 속성을 분리
- **특징**: 원자값(Atomic Value)만을 허용

### 2차 정규화 (2NF)

- **목적**: 주식별자에 종속적이지 않은 속성의 분리
- **핵심**: 부분 종속(Partial Dependency) 속성의 분리

### 3차 정규화 (3NF)

- **목적**: 속성에 종속적인 속성의 분리
- **핵심**: 이행 종속(Transitive Dependency) 속성의 분리

## 오브젝트 분석 vs 정규화 엔티티 타입 분석

### 오브젝트 분석

- 실세계에서 발생하는 현상을 오브젝트 유형별로 정리
- 오브젝트간 종속관계를 활용하여 엔티티 타입 도출 및 정제

### 정규화 엔티티 타입 도출

- 실세계에서 발생하는 데이터들을 정리하여 중복된 속성을 제거
- 종속관계를 활용하여 주식별자에 의한 속성 배치
- 속성간 종속적인 관계를 분리
