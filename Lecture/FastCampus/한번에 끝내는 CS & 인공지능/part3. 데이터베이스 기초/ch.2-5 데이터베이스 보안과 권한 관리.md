# 데이터베이스 보안 및 권한 관리

## 1. 물리적 데이터베이스 보안

### 목적

자연재해 또는 물리적 손실을 발생시키는 위험으로부터 데이터베이스를 보호

### 주요 보안 조치

- **물리적 공간 확보 및 잠금 장치**
    
    - 서버실 등 데이터베이스가 위치한 공간의 물리적 보안
    - 적절한 잠금 시스템 구축
- **보안 카메라 설치**
    
    - 하드웨어 및 메탈 장비 주변 감시
    - 24시간 모니터링 체계
- **장비 접근 제한**
    
    - 권한이 있는 인원만 장비에 접근 가능
    - 접근 권한 관리 시스템 운영

## 2. 권한 관리를 통한 데이터베이스 보안

### 접근 제한

- **로그인 단계 보안**
    - 로그인 과정에서 접근 제한 기능 제공
    - 인증 및 인가 프로세스 구현

### 권한 관리 체계

- **사용자 계정 관리**
    - 데이터베이스 사용자 계정 생성, 변경, 제거
    - DBMS 관리자가 전담하여 관리

## 3. 권한 부여 및 삭제

### 권한 부여 (GRANT)

- **범위**: 데이터베이스에 존재하는 모든 객체
- **방법**: `GRANT` 명령어 사용
- **기능**: 다른 사용자에게 객체 사용 권한 부여

### 권한 삭제 (REVOKE)

- **기능**: 기존에 부여된 권한을 삭제
- **방법**: `REVOKE` 명령어 사용

## 핵심 포인트

1. **다층 보안**: 물리적 보안과 논리적 보안을 함께 적용
2. **권한 관리**: 최소 권한 원칙에 따른 체계적 관리
3. **관리자 역할**: DBMS 관리자의 중요한 책임
4. **명령어 활용**: GRANT/REVOKE를 통한 동적 권한 관리
