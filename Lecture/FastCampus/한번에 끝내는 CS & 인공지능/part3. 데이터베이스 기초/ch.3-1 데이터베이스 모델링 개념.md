# 데이터 모델링

## 1. 데이터 모델링 정의

데이터 모델링은 **조직의 정보 수집과 관리 시스템을 정의하는 시각적 표현 또는 청사진을 생성하는 프로세스**입니다.

### 주요 특징

- **정보화 시스템 구축을 위한 데이터 분석**
    
    - 어떤 데이터가 존재하는지 파악
    - 업무에 필요한 정보가 무엇인지 분석
- **시각적 표현**
    
    - 정보 시스템의 모습을 적절한 표기법으로 표현
    - 업무에 필요한 데이터를 체계적으로 분석하고 설계
- **시스템 구축 방법론 활용**
    
    - 데이터를 분석하고 설계하여 정보화 시스템 구축

## 2. 데이터 모델링 필요성

### 조직 차원

- **데이터 문서화 및 시스템 설계의 일관성 조정**
- **업무 조직과 기술 조직 간 의사소통 및 중재 역할**

### 기술적 차원

- **다양한 소스에서 많은 데이터 수집 관리**
- **정확한 데이터 분석 지원**
- **DBMS 구축에 필요한 제반 기술들의 효율적 적용 방안 제시**

## 3. 모델링 관점 3가지

### 1. 데이터 관점 (What/Data)

- **목적**: 업무와 데이터의 관계 파악
- **내용**:
    - 업무가 어떤 데이터와 관련이 있는지 분석
    - 데이터 간의 관계 정의

### 2. 프로세스 관점 (How/Process)

- **목적**: 업무 처리 방법 정의
- **내용**:
    - 업무를 통해 어떤 일을 처리하는지 분석
    - 무엇을 해야 하는지 모델링

### 3. 데이터와 프로세스의 상관 관점 (Interaction)

- **목적**: 데이터와 프로세스의 상호작용 분석
- **내용**:
    - 업무 처리 방법에 따른 데이터 영향도 분석
    - 프로세스와 데이터의 상호관계 모델링

## 4. 데이터 모델링 진행 시 중요 요소

### 핵심 고려사항

1. **업무 특성 (Domain)**
    
    - 해당 업무 영역의 특성과 범위
2. **업무 간의 관계 (Relationships)**
    
    - 각 업무 간의 연관성과 의존성
3. **업무의 성격 (Attributes)**
    
    - 업무가 가지는 고유한 특성과 속성

## 정리

데이터 모델링은 단순한 데이터 구조 설계를 넘어서 조직의 업무와 데이터, 프로세스를 통합적으로 분석하고 설계하는 중요한 활동입니다. 성공적인 정보화 시스템 구축을 위해서는 세 가지 관점을 균형있게 고려하여 모델링을 진행해야 합니다.
