# 관계대수 및 관계연산 정리

## 관계대수 (Relational Algebra)

- 릴레이션에서 원하는 결과를 얻기 위해 수학의 대수와 같은 연산을 이용하여 질의하는 방법을 기술
- 절차적 언어로 하나 이상의 릴레이션에 연산을 수행하여 결과 릴레이션이 나오기까지의 절차를 확인할 수 있는 방법을 제공
- SQL언어는 관계 해석을 기반으로 하지만, DBMS 내부에서는 관계 대수에 기반을 둔 연산을 수행

## 수학의 대수

- 대수학을 의미하며, 변수와 상수를 사용해서 다양한 연산을 정의하고, 이 연산들을 조합해서 복잡한 식을 만들고 계산하는 것
- 체계적이고 정형화된 연산 규칙을 통해 단계별로 문제를 해결하는 것

## 관계의 수학적 의미

- 관계 데이터베이스는 릴레이션이라는 수학적 개념에 기초
- 집합은 숫자, 문자, 사람 등 객체의 모임

### 카티션 프로덕트 예시

집합 A={1, 3, 5}, B={2, 4}가 있을 경우:

- **두 집합의 카티션프로덕트 A×B**는 A원소와 B원소의 순서쌍의 조합
    
    - A×B = {(1,2), (1,4), (3,2), (3,4), (5,2), (5,4)}
- **릴레이션 R**은 카티션프로덕트의 부분집합으로 정의
    
    - R1 = {(1,2), (1,4), (3,2)}
    - R2 = {(3,4), (5,2), (5,4)}

### 부분집합과 릴레이션

- 원소갯수가 n인 집합 S의 부분집합 개수는 2^n개로 표현
- 현재 집합의 카티션프로덕트는 2^(|A|×|B|)
- 즉, 2^6 = 64개의 릴레이션 가능

### 도메인

- 카티션프로덕트의 기초 집합 A, B, C 각각이 가질 수 있는 값의 범위를 도메인이라고 함
- 집합 연산은 합집합, 교집합, 카티션프로덕트 등이 있음

## 관계연산

### 셀렉션 (Selection)

- 릴레이션의 튜플을 추출하기 위한 연산

### 프로젝션 (Projection)

- 릴레이션의 속성을 추출하기 위한 연산으로 단항 연산자

### 합집합 (Union)

- 두 개의 릴레이션을 합하여 하나의 릴레이션을 반환
- 반환되는 결과는 첫번째 릴레이션의 속성 이름을 가짐

### 교집합 (Intersection)

- 두 개의 릴레이션이 공통으로 가지고 있는 튜플을 반환

### 차집합 (Set-difference)

- 첫 번째 릴레이션에는 속하고, 두 번째에는 속하지 않는 튜플 반환

### 카티션 프로덕트 (Cartesian Product)

- 두 개의 릴레이션을 연결하여 하나의 릴레이션을 반환

## 조인 (Join)

- 두 릴레이션의 공통 속성을 기준으로 속성 값이 같은 튜플을 수평으로 결합하는 연산
