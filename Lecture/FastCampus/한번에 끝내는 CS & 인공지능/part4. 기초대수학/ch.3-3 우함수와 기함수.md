# 우함수와 기함수 (Even Function & Odd Function)

## 우함수 (Even Function)

### 정의

- **대칭성**: y축을 기준으로 좌우 대칭인 함수
- **수학적 조건**: f(-x) = f(x)
- 함수 그래프가 y축에 대해 대칭적으로 나타남

### 특징

- x를 -x로 바꿔도 함수값이 동일함
- 그래프의 왼쪽 부분과 오른쪽 부분이 y축을 기준으로 대칭

### 예시

- y = x²
- y = x⁴
- y = cos x
- y = 1 (상수함수)

---

## 기함수 (Odd Function)

### 정의

- **대칭성**: 원점을 기준으로 점대칭인 함수
- **수학적 조건**: f(-x) = -f(x)
- 함수 그래프가 원점(0, 0)에 대해 대칭적으로 나타남

### 특징

- x를 -x로 바꾸면 함수값의 부호가 바뀜
- 그래프를 원점 중심으로 180° 회전해도 동일한 모양

### 예시

- y = x
- y = x³
- y = sin x
- y = tan x

---

## 구분 방법

1. **그래프로 판별**
    
    - 우함수: y축 대칭
    - 기함수: 원점 대칭
2. **대수적 판별**
    
    - 우함수: f(-x) = f(x) 확인
    - 기함수: f(-x) = -f(x) 확인

---

## 우함수와 기함수의 연산 특징

### 상수배

- **상수 × 기함수 = 기함수**
    - f(-x) = -f(x) ⟹ cf(-x) = -cf(x)
- **상수 × 우함수 = 우함수**
    - f(-x) = f(x) ⟹ cf(-x) = cf(x)

### 덧셈과 뺄셈

- **우함수 ± 우함수 = 우함수**
- **기함수 ± 기함수 = 기함수**

### 곱셈

- **기함수 × 기함수 = 우함수**
- **기함수 × 우함수 = 기함수**
- **우함수 × 우함수 = 우함수**

---

## 참고사항

- 모든 함수가 우함수나 기함수인 것은 아님
- 어떤 함수는 우함수도 기함수도 아닐 수 있음
- 우함수와 기함수의 성질을 이용하면 함수의 적분이나 급수 계산이 간단해질 수 있음
- 연산 특징을 활용하면 복잡한 함수의 대칭성을 쉽게 판별할 수 있음
