# 구간 (Intervals)

## 구간의 정의

구간은 실수 집합의 부분집합으로, 두 실수 사이의 연속적인 값들의 집합을 나타냅니다.

## 구간의 종류

### 1. 닫힌 구간 (Closed Intervals)

**표기**: [a, b] ⊆ ℝ

**정의**: a ≤ x ≤ b인 모든 실수 x의 집합

**특징**:

- 양 끝점 a, b가 구간에 포함됨
- "이상, 이하"의 개념
- 집합 표기: {x ∈ ℝ | a ≤ x ≤ b}

**예시**:

- [-3, 1] = {x ∈ ℝ | -3 ≤ x ≤ 1}
- [0, 5] = {x ∈ ℝ | 0 ≤ x ≤ 5}

### 2. 열린 구간 (Open Intervals)

**표기**: (a, b) ⊆ ℝ

**정의**: a < x < b인 모든 실수 x의 집합

**특징**:

- 양 끝점 a, b가 구간에 포함되지 않음
- "초과, 미만"의 개념
- 집합 표기: {x ∈ ℝ | a < x < b}

**예시**:

- (-3, 1) = {x ∈ ℝ | -3 < x < 1}
- (0, 2) = {x ∈ ℝ | 0 < x < 2}

### 3. 반열린 구간 / 반닫힌 구간 (Half-open/Half-closed Intervals)

#### 3-1. 왼쪽 열린, 오른쪽 닫힌 구간

**표기**: (a, b] ⊆ ℝ

**정의**: a < x ≤ b인 모든 실수 x의 집합

**특징**:

- 왼쪽 끝점 a는 포함되지 않음
- 오른쪽 끝점 b는 포함됨

**예시**: (-3, 1] = {x ∈ ℝ | -3 < x ≤ 1}

#### 3-2. 왼쪽 닫힌, 오른쪽 열린 구간

**표기**: [a, b) ⊆ ℝ

**정의**: a ≤ x < b인 모든 실수 x의 집합

**특징**:

- 왼쪽 끝점 a는 포함됨
- 오른쪽 끝점 b는 포함되지 않음

**예시**: [-3, 1) = {x ∈ ℝ | -3 ≤ x < 1}

### 4. 무한 구간 (Intervals with Infinity)

#### 4-1. 오른쪽 무한 구간

**표기**: [a, ∞) ⊆ ℝ 또는 (a, ∞) ⊆ ℝ

**정의**:

- [a, ∞) = {x ∈ ℝ | x ≥ a}
- (a, ∞) = {x ∈ ℝ | x > a}

**예시**:

- [-3, ∞) = {x ∈ ℝ | x ≥ -3}
- (0, ∞) = {x ∈ ℝ | x > 0} (양의 실수)

#### 4-2. 왼쪽 무한 구간

**표기**: (-∞, b] ⊆ ℝ 또는 (-∞, b) ⊆ ℝ

**정의**:

- (-∞, b] = {x ∈ ℝ | x ≤ b}
- (-∞, b) = {x ∈ ℝ | x < b}

**예시**:

- (-∞, 5] = {x ∈ ℝ | x ≤ 5}
- (-∞, 0) = {x ∈ ℝ | x < 0} (음의 실수)

#### 4-3. 전체 실수 집합

**표기**: (-∞, ∞) = ℝ

**정의**: 모든 실수의 집합

## 구간의 연산

### 1. 구간의 합집합 (Union of Intervals)

두 구간의 합집합은 두 구간에 속하는 모든 점들의 집합입니다.

**예시**:

- [1, 3] ∪ [2, 5] = [1, 5]
- [1, 2] ∪ [3, 4] = [1, 2] ∪ [3, 4] (분리된 구간)
- (-∞, 1] ∪ [3, ∞) = (-∞, 1] ∪ [3, ∞)

### 2. 구간의 교집합 (Intersection of Intervals)

두 구간의 교집합은 두 구간에 모두 속하는 점들의 집합입니다.

**예시**:

- [1, 4] ∩ [2, 6] = [2, 4]
- [1, 3] ∩ [4, 6] = ∅ (공집합)
- (-∞, 2] ∩ [0, ∞) = [0, 2]

## 구간의 성질

### 1. 연결성 (Connectedness)

- 구간의 모든 점은 연속적으로 연결되어 있음
- 구간 안의 두 점 사이에는 무한히 많은 점이 존재

### 2. 길이 (Length)

- 유한 구간 [a, b]의 길이: b - a
- 무한 구간의 길이: ∞

### 3. 중점 (Midpoint)

- 구간 [a, b]의 중점: (a + b)/2

## 응용 분야

### 수학

- 함수의 정의역과 치역
- 부등식의 해집합
- 적분의 적분구간

### 통계학

- 신뢰구간 (Confidence Interval)
- 확률분포의 지지집합

### 공학

- 제어 시스템의 안정 범위
- 센서의 측정 범위

### 컴퓨터 과학

- 알고리즘의 시간 복잡도 분석
- 데이터 범위 검증

## 주요 표기법 정리

|구간 표기|부등식 표현|의미|
|---|---|---|
|[a, b]|a ≤ x ≤ b|닫힌 구간|
|(a, b)|a < x < b|열린 구간|
|[a, b)|a ≤ x < b|반열린 구간|
|(a, b]|a < x ≤ b|반열린 구간|
|[a, ∞)|x ≥ a|오른쪽 무한 구간|
|(a, ∞)|x > a|오른쪽 무한 구간|
|(-∞, b]|x ≤ b|왼쪽 무한 구간|
|(-∞, b)|x < b|왼쪽 무한 구간|
|(-∞, ∞)|모든 x|전체 실수 집합|
