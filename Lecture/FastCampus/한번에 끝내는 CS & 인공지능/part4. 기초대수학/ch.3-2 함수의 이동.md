# 함수의 이동
## 함수의 평행이동 (Translation)

## 개념 정리

함수의 평행이동은 **함수의 그래프를 상하좌우로 이동**시키는 변형입니다.

## 1. 수평 평행이동 (Horizontal Translation)

### 공식

```
y = f(x) → y = f(x - a)
```

### 이동 방향

- **a > 0**: 오른쪽으로 a만큼 이동
- **a < 0**: 왼쪽으로 |a|만큼 이동

### 핵심 이해

**"괄호 안이 0이 되는 x값이 새로운 중심"**

|원래 함수|변형된 함수|이동 방향|
|---|---|---|
|y = f(x)|y = f(x - 3)|오른쪽 3칸|
|y = f(x)|y = f(x + 2)|왼쪽 2칸|

### 예시: y = x²

```
y = x²          → 꼭짓점: (0, 0)
y = (x - 1)²    → 꼭짓점: (1, 0)  [오른쪽 1칸]
y = (x + 2)²    → 꼭짓점: (-2, 0) [왼쪽 2칸]
```

## 2. 수직 평행이동 (Vertical Translation)

### 공식

```
y = f(x) → y = f(x) + b
```

### 이동 방향

- **b > 0**: 위로 b만큼 이동
- **b < 0**: 아래로 |b|만큼 이동

### 예시: y = x²

```
y = x²          → 꼭짓점: (0, 0)
y = x² + 3      → 꼭짓점: (0, 3)  [위로 3칸]
y = x² - 2      → 꼭짓점: (0, -2) [아래로 2칸]
```

## 3. 수평 + 수직 평행이동

### 일반형

```
y = f(x) → y = f(x - a) + b
```

### 이동 효과

- **수평**: a만큼 오른쪽 이동
- **수직**: b만큼 위로 이동

### 예시: y = x²

```
y = x²                    → 꼭짓점: (0, 0)
y = (x - 2)² + 3         → 꼭짓점: (2, 3)  [오른쪽 2칸, 위로 3칸]
y = (x + 1)² - 4         → 꼭짓점: (-1, -4) [왼쪽 1칸, 아래로 4칸]
```

## 기억법과 주의사항

### 🔑 핵심 기억법

1. **수평 이동**: "괄호 안이 0이 되는 x값 = 새로운 중심"
2. **수직 이동**: "더하면 위로, 빼면 아래로"

### ⚠️ 주의사항

- 수평 이동에서 **부호가 직관과 반대**
    - 오른쪽 이동: f(x - a) (음수 사용)
    - 왼쪽 이동: f(x + a) (양수 사용)

### 📝 검증 방법

변형된 함수에서 **특정 점의 새로운 위치**를 계산해보면 이해가 쉽습니다.

**예시**: y = x²에서 점 (2, 4)가 y = (x-1)² + 3에서는?

- 수평 +1, 수직 +3 이동
- 새로운 위치: (2+1, 4+3) = (3, 7)

## 요약표

|변형|공식|이동 방향|예시|
|---|---|---|---|
|수평|f(x-a)|a > 0: 오른쪽|f(x-2): 오른쪽 2칸|
|수직|f(x)+b|b > 0: 위쪽|f(x)+3: 위로 3칸|
|복합|f(x-a)+b|수평+수직|f(x-2)+3: 오른쪽 2칸, 위로 3칸|

# 함수의 대칭이동

## 1. Y축 대칭 (y축에 대한 대칭)

**변환 공식:** `y = f(x)` → `y = f(-x)`

- x를 -x로 치환
- 그래프가 y축을 기준으로 좌우 대칭이 됨

**예시:**

- 원함수: `y = (x - 2)² + 1`
- 대칭이동: `y = (-x - 2)² + 1 = (x + 2)² + 1`

---

## 2. X축 대칭 (x축에 대한 대칭)

**변환 공식:** `y = f(x)` → `y = -f(x)`

- 함수값에 -1을 곱함
- 그래프가 x축을 기준으로 상하 대칭이 됨

**예시:**

- 원함수: `y = (x - 2)² + 1`
- 대칭이동: `y = -[(x - 2)² + 1] = -(x - 2)² - 1`

---

## 3. 원점 대칭 (원점에 대한 대칭)

**변환 공식:** `y = f(x)` → `y = -f(-x)`

- x를 -x로 치환하고 함수값에 -1을 곱함
- Y축 대칭과 X축 대칭을 모두 적용한 것과 같음
- 점 (a, b)가 점 (-a, -b)로 이동

**예시:**

- 원함수: `y = (x - 2)² + 1`
- 대칭이동: `y = -[(-x - 2)² + 1] = -(x + 2)² - 1`

---

## 대칭이동 요약표

|대칭 종류|변환 공식|변환 방법|
|---|---|---|
|Y축 대칭|`y = f(-x)`|x → -x|
|X축 대칭|`y = -f(x)`|y → -y|
|원점 대칭|`y = -f(-x)`|x → -x, y → -y|

---

## 기하학적 의미

- **Y축 대칭**: 그래프를 y축을 기준으로 접어서 포갠 것
- **X축 대칭**: 그래프를 x축을 기준으로 뒤집은 것
- **원점 대칭**: 그래프를 원점을 중심으로 180° 회전한 것

---

## 주의사항

1. 대칭이동은 그래프의 모양은 유지하고 위치만 변경
2. Y축 대칭에서는 정의역의 부호가 바뀜
3. X축 대칭에서는 치역의 부호가 바뀜
4. 원점 대칭은 Y축 대칭과 X축 대칭을 순서에 관계없이 모두 적용한 결과

---
# 함수의 수축과 팽창 (Dilations)

## 1. 수평적 Dilations (Horizontal Dilations)

**변환 공식:** `y = f(x)` → `y = f(ax)`

- x에 상수 a를 곱함
- 그래프가 수평 방향으로 확대/축소됨

### 수평적 변환의 효과

- **a > 1**: 수평 압축 (그래프가 y축 쪽으로 좁아짐)
- **0 < a < 1**: 수평 팽창 (그래프가 y축에서 멀어짐)

**예시:**

- 원함수: `y = x² + 1`
- a = 2일 때: `y = (2x)² + 1 = 4x² + 1` (수평 압축)
- a = 1/2일 때: `y = (1/2·x)² + 1 = (1/4)x² + 1` (수평 팽창)

---

## 2. 수직적 Dilations (Vertical Dilations)

**변환 공식:** `y = f(x)` → `y = (1/b)f(x)`

- 함수값에 상수 1/b를 곱함
- 그래프가 수직 방향으로 확대/축소됨

### 수직적 변환의 효과

- **b > 1**: 수직 압축 (그래프가 x축 쪽으로 줄어듦)
- **0 < b < 1**: 수직 팽창 (그래프가 x축에서 멀어짐)

**예시:**

- 원함수: `y = x² + 1`
- b = 2일 때: `y = (1/2)(x² + 1) = (1/2)x² + 1/2` (수직 압축)
- b = 1/2일 때: `y = 2(x² + 1) = 2x² + 2` (수직 팽창)

---

## 3. 수평/수직적 Dilations (Combined Dilations)

**변환 공식:** `y = f(x)` → `y = (1/b)f(ax)`

- 수평과 수직 변환을 동시에 적용
- 그래프가 두 방향으로 모두 확대/축소됨

**예시:**

- 원함수: `y = x² + 1`
- a = 2, b = 1/2일 때: `y = 2·f(2x) = 2(2x)² + 2 = 8x² + 2`

---

## 압축과 팽창의 구분

### Compressing (압축)

- **수평 압축**: a > 1
- **수직 압축**: b > 1
- 그래프가 원점 쪽으로 줄어듦

### Stretching (팽창)

- **수평 팽창**: 0 < a < 1
- **수직 팽창**: 0 < b < 1
- 그래프가 원점에서 멀어짐

---

## Dilations 요약표

|변환 종류|공식|a 또는 b 값|효과|
|---|---|---|---|
|수평 압축|`y = f(ax)`|a > 1|그래프가 y축 쪽으로 압축|
|수평 팽창|`y = f(ax)`|0 < a < 1|그래프가 y축에서 멀어짐|
|수직 압축|`y = (1/b)f(x)`|b > 1|그래프가 x축 쪽으로 압축|
|수직 팽창|`y = (1/b)f(x)`|0 < b < 1|그래프가 x축에서 멀어짐|

---

## 기하학적 의미

- **수평 Dilation**: 그래프의 폭이 변함 (높이는 그대로)
- **수직 Dilation**: 그래프의 높이가 변함 (폭은 그대로)
- **복합 Dilation**: 그래프의 전체적인 크기가 변함

---

## 주의사항

1. **수평 변환**: x에 곱해지는 계수가 클수록 그래프는 압축됨 (직관과 반대)
2. **수직 변환**: y에 곱해지는 계수가 클수록 그래프는 팽창됨 (직관과 일치)
3. **변환 순서**: 일반적으로 수평 변환을 먼저 적용한 후 수직 변환을 적용
4. **기준점**: 모든 Dilation은 원점 (0, 0)을 기준으로 함

# 함수의 추가적인 대칭이동

## 기본 대칭이동 복습

- **Y축 대칭**: `y = f(x)` → `y = f(-x)`
- **X축 대칭**: `y = f(x)` → `y = -f(x)`
- **원점 대칭**: `y = f(x)` → `y = -f(-x)`

---

## 임의의 직선에 대한 대칭이동

### 1. x = a에 대한 대칭 (수직선 대칭)

**변환 공식:** `x → 2a - x`

- 점 (x, y)가 직선 x = a에 대해 대칭인 점은 (2a - x, y)
- 직선 x = a로부터 같은 거리에 있는 반대편 점으로 이동

**예시:**

- **x = 1에 대한 대칭**: `x → 2(1) - x = 2 - x`
- 원함수: `y = f(x)`
- 대칭이동: `y = f(2 - x)`

### 실제 적용 예시

- 원함수: `y = x²`
- x = 1 대칭: `y = (2 - x)² = (x - 2)²`

---

### 2. y = b에 대한 대칭 (수평선 대칭)

**변환 공식:** `y → 2b - y`

- 점 (x, y)가 직선 y = b에 대해 대칭인 점은 (x, 2b - y)
- 직선 y = b로부터 같은 거리에 있는 반대편 점으로 이동

**예시:**

- **y = 1에 대한 대칭**: `y → 2(1) - y = 2 - y`
- 원함수: `y = f(x)`
- 대칭이동: `2 - y = f(x)` → `y = 2 - f(x)`

### 실제 적용 예시

- 원함수: `y = x²`
- y = 1 대칭: `2 - y = x²` → `y = 2 - x² = -x² + 2`

---

## 대칭이동 과정 단계별 분석

### x = a 대칭의 기하학적 의미

1. 점 (x, y)에서 직선 x = a까지의 거리: |x - a|
2. 대칭점은 직선 반대편에서 같은 거리에 위치
3. 대칭점의 x좌표: a - (x - a) = 2a - x
4. y좌표는 변하지 않음

### y = b 대칭의 기하학적 의미

1. 점 (x, y)에서 직선 y = b까지의 거리: |y - b|
2. 대칭점은 직선 반대편에서 같은 거리에 위치
3. 대칭점의 y좌표: b - (y - b) = 2b - y
4. x좌표는 변하지 않음

---

## 대칭이동 요약표

|대칭 기준|변환 공식|점의 이동|함수 변환|
|---|---|---|---|
|Y축 (x = 0)|x → -x|(x, y) → (-x, y)|y = f(-x)|
|X축 (y = 0)|y → -y|(x, y) → (x, -y)|y = -f(x)|
|원점|x → -x, y → -y|(x, y) → (-x, -y)|y = -f(-x)|
|x = a|x → 2a - x|(x, y) → (2a-x, y)|y = f(2a-x)|
|y = b|y → 2b - y|(x, y) → (x, 2b-y)|y = 2b - f(x)|

---

## 실전 예제

### 예제 1: y = x² + 3x + 2를 x = 1에 대해 대칭이동

- 변환: x → 2 - x
- 결과: y = (2-x)² + 3(2-x) + 2
- 전개: y = (2-x)² + 6 - 3x + 2 = x² - 4x + 4 + 6 - 3x + 2 = x² - 7x + 12

### 예제 2: y = x²을 y = 3에 대해 대칭이동

- 변환: y → 2(3) - y = 6 - y
- 과정: 6 - y = x² → y = 6 - x² = -x² + 6

---

## 활용 팁

1. **순서 주의**: 여러 변환을 적용할 때는 순서가 중요
2. **검증 방법**: 특정 점을 선택하여 변환 전후 위치 확인
3. **대칭축 찾기**: 원함수와 변환 함수의 교점들이 대칭축 위에 위치
4. **조합 가능**: 여러 대칭이동을 연속으로 적용 가능

---

## 주의사항

- x = a 대칭에서는 **x를 치환**하므로 함수의 형태가 변함
- y = b 대칭에서는 **y를 치환**하므로 방정식을 y에 대해 정리해야 함
- 대칭축이 원점을 지나지 않는 경우 계산이 복잡해질 수 있음
