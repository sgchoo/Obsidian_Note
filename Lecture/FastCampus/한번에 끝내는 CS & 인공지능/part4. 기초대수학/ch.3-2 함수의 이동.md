# 함수의 이동
## 함수의 평행이동 (Translation)

## 개념 정리

함수의 평행이동은 **함수의 그래프를 상하좌우로 이동**시키는 변형입니다.

## 1. 수평 평행이동 (Horizontal Translation)

### 공식

```
y = f(x) → y = f(x - a)
```

### 이동 방향

- **a > 0**: 오른쪽으로 a만큼 이동
- **a < 0**: 왼쪽으로 |a|만큼 이동

### 핵심 이해

**"괄호 안이 0이 되는 x값이 새로운 중심"**

|원래 함수|변형된 함수|이동 방향|
|---|---|---|
|y = f(x)|y = f(x - 3)|오른쪽 3칸|
|y = f(x)|y = f(x + 2)|왼쪽 2칸|

### 예시: y = x²

```
y = x²          → 꼭짓점: (0, 0)
y = (x - 1)²    → 꼭짓점: (1, 0)  [오른쪽 1칸]
y = (x + 2)²    → 꼭짓점: (-2, 0) [왼쪽 2칸]
```

## 2. 수직 평행이동 (Vertical Translation)

### 공식

```
y = f(x) → y = f(x) + b
```

### 이동 방향

- **b > 0**: 위로 b만큼 이동
- **b < 0**: 아래로 |b|만큼 이동

### 예시: y = x²

```
y = x²          → 꼭짓점: (0, 0)
y = x² + 3      → 꼭짓점: (0, 3)  [위로 3칸]
y = x² - 2      → 꼭짓점: (0, -2) [아래로 2칸]
```

## 3. 수평 + 수직 평행이동

### 일반형

```
y = f(x) → y = f(x - a) + b
```

### 이동 효과

- **수평**: a만큼 오른쪽 이동
- **수직**: b만큼 위로 이동

### 예시: y = x²

```
y = x²                    → 꼭짓점: (0, 0)
y = (x - 2)² + 3         → 꼭짓점: (2, 3)  [오른쪽 2칸, 위로 3칸]
y = (x + 1)² - 4         → 꼭짓점: (-1, -4) [왼쪽 1칸, 아래로 4칸]
```

## 기억법과 주의사항

### 🔑 핵심 기억법

1. **수평 이동**: "괄호 안이 0이 되는 x값 = 새로운 중심"
2. **수직 이동**: "더하면 위로, 빼면 아래로"

### ⚠️ 주의사항

- 수평 이동에서 **부호가 직관과 반대**
    - 오른쪽 이동: f(x - a) (음수 사용)
    - 왼쪽 이동: f(x + a) (양수 사용)

### 📝 검증 방법

변형된 함수에서 **특정 점의 새로운 위치**를 계산해보면 이해가 쉽습니다.

**예시**: y = x²에서 점 (2, 4)가 y = (x-1)² + 3에서는?

- 수평 +1, 수직 +3 이동
- 새로운 위치: (2+1, 4+3) = (3, 7)

## 요약표

|변형|공식|이동 방향|예시|
|---|---|---|---|
|수평|f(x-a)|a > 0: 오른쪽|f(x-2): 오른쪽 2칸|
|수직|f(x)+b|b > 0: 위쪽|f(x)+3: 위로 3칸|
|복합|f(x-a)+b|수평+수직|f(x-2)+3: 오른쪽 2칸, 위로 3칸|

# 함수의 대칭이동

## 1. Y축 대칭 (y축에 대한 대칭)

**변환 공식:** `y = f(x)` → `y = f(-x)`

- x를 -x로 치환
- 그래프가 y축을 기준으로 좌우 대칭이 됨

**예시:**

- 원함수: `y = (x - 2)² + 1`
- 대칭이동: `y = (-x - 2)² + 1 = (x + 2)² + 1`

---

## 2. X축 대칭 (x축에 대한 대칭)

**변환 공식:** `y = f(x)` → `y = -f(x)`

- 함수값에 -1을 곱함
- 그래프가 x축을 기준으로 상하 대칭이 됨

**예시:**

- 원함수: `y = (x - 2)² + 1`
- 대칭이동: `y = -[(x - 2)² + 1] = -(x - 2)² - 1`

---

## 3. 원점 대칭 (원점에 대한 대칭)

**변환 공식:** `y = f(x)` → `y = -f(-x)`

- x를 -x로 치환하고 함수값에 -1을 곱함
- Y축 대칭과 X축 대칭을 모두 적용한 것과 같음
- 점 (a, b)가 점 (-a, -b)로 이동

**예시:**

- 원함수: `y = (x - 2)² + 1`
- 대칭이동: `y = -[(-x - 2)² + 1] = -(x + 2)² - 1`

---

## 대칭이동 요약표

|대칭 종류|변환 공식|변환 방법|
|---|---|---|
|Y축 대칭|`y = f(-x)`|x → -x|
|X축 대칭|`y = -f(x)`|y → -y|
|원점 대칭|`y = -f(-x)`|x → -x, y → -y|

---

## 기하학적 의미

- **Y축 대칭**: 그래프를 y축을 기준으로 접어서 포갠 것
- **X축 대칭**: 그래프를 x축을 기준으로 뒤집은 것
- **원점 대칭**: 그래프를 원점을 중심으로 180° 회전한 것

---

## 주의사항

1. 대칭이동은 그래프의 모양은 유지하고 위치만 변경
2. Y축 대칭에서는 정의역의 부호가 바뀜
3. X축 대칭에서는 치역의 부호가 바뀜
4. 원점 대칭은 Y축 대칭과 X축 대칭을 순서에 관계없이 모두 적용한 결과
