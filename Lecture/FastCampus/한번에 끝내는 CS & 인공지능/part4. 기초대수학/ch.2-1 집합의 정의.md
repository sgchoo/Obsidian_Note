# 집합론 기초 (Set Theory Basics)

## 집합의 정의 (Definition of Set)

**집합(Set)** = 서로 다르고 명확히 정의된 사물(또는 원소)들의 **모음**

### 집합의 특징

- **Distinct (구별됨)**: 서로 같지 않은 원소들
- **Things**: 서로 같은 종류의 객체들
- **다양한 형태**: 집합은 반드시 숫자일 필요가 없음
    - 예시: 자연수, 문자, 직사각형, 이미지, 사람 등

## 집합 표현 방법

### 1. 원소 나열법 (Enumerating Elements)

```
Set = {element₁, element₂, …, elementₙ}
```

**예시:**

- A = {1, 2, 3, 4, 5}
- B = {a, b, c, d}
- C = {빨강, 파랑, 노랑}

### 2. 조건 제시법 (Set Builder Notation)

```
Set = {element | element's condition}
```

**예시:**

- A = {x | x는 10보다 작은 자연수}
- B = {x | x는 짝수이고 0 < x < 20}

## 일반적인 수 집합들 (Common Number Sets)

### 기본 수 집합

1. **자연수 (Natural Numbers)** - ℕ
    - {1, 2, 3, 4, 5, ...}
2. **전체수 (Whole Numbers)** - W
    - {0, 1, 2, 3, 4, 5, ...}
3. **정수 (Integers)** - ℤ
    - {..., -3, -2, -1, 0, 1, 2, 3, ...}
4. **유리수 (Rational Numbers)** - ℚ
    - 분수로 나타낼 수 있는 수 (p/q, q≠0)
5. **무리수 (Irrational Numbers)**
    - 분수로 나타낼 수 없는 수 (√2, π, e 등)
6. **실수 (Real Numbers)** - ℝ
    - 유리수와 무리수를 합친 집합
7. **복소수 (Complex Numbers)** - ℂ
    - a + bi 형태의 수 (a, b는 실수, i는 허수단위)
