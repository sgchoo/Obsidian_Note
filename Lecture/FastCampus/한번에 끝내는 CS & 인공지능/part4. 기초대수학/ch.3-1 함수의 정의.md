# 함수의 정의와 종류

## 함수의 정의

두 집합 X, Y에 대해 **x ∈ X가 y ∈ Y에 오로지 하나만 대응되는 관계**

```
X → Function → Y
```

## 함수의 집합

### Domain (정의역)

- **X**: 함수의 입력값이 될 수 있는 모든 값들의 집합
- 함수가 정의되는 x 값들의 범위

### Codomain (공역)

- **Y**: 함수의 출력값이 될 수 있는 모든 값들의 집합
- 함수가 매핑될 수 있는 y 값들의 전체 집합

### Range (치역)

- **R**: 함수의 실제 출력값들의 집합
- 실제로 함수에 의해 매핑되는 y 값들의 집합
- **R ⊆ Y** (치역은 공역의 부분집합)

## 함수의 종류

### 1. Injective Function (단사 함수)

- **특징**: 같은 y는 한번씩만 대응된다
- **조건**: x₁ ≠ x₂ ⟹ f(x₁) ≠ f(x₂)
- **의미**: 서로 다른 입력값은 서로 다른 출력값을 가짐

### 2. Surjective Function (전사 함수)

- **특징**: 모든 y는 적어도 하나의 x에 대응
- **조건**: Codomain = Range (공역 = 치역)
- **의미**: 공역의 모든 원소가 적어도 하나의 정의역 원소와 대응

### 3. Bijective Function (전단사 함수)

- **특징**: Injective와 Surjective 모두 만족
- **조건**: 일대일 대응 관계
- **의미**: 완벽한 대응 관계로 역함수가 존재

## 함수의 그래프

**모든 Domain의 원소에 대한 함숫값의 쌍을 좌표계 위에 나타낸 것**

- **형태**: (x, f(x)) 형태의 순서쌍들의 집합
- **표현**: 2차원 좌표계에서 점들의 모임
- **조건**: 수직선 테스트 (Vertical Line Test)를 만족해야 함
    - 임의의 수직선이 그래프와 최대 한 점에서만 만남

## 함수의 변형 (Transformations)

### 1. Reflection (대칭이동)

- **x축 대칭**: f(x) → -f(x)
- **y축 대칭**: f(x) → f(-x)
- **원점 대칭**: f(x) → -f(-x)

### 2. Translation (평행이동)

- **수평 이동**: f(x) → f(x - h) (h > 0이면 오른쪽으로 이동)
- **수직 이동**: f(x) → f(x) + k (k > 0이면 위로 이동)
- **일반형**: f(x) → f(x - h) + k

### 3. Dilation (수축/팽창)

- **수평 방향**: f(x) → f(ax) (a > 1이면 수축, 0 < a < 1이면 팽창)
- **수직 방향**: f(x) → bf(x) (b > 1이면 팽창, 0 < b < 1이면 수축)
- **일반형**: f(x) → bf(ax)

## 요약

|함수 종류|조건|특징|
|---|---|---|
|Injective|서로 다른 x → 서로 다른 y|일대일 매핑|
|Surjective|모든 y에 대응하는 x 존재|전체 커버|
|Bijective|Injective + Surjective|완전 대응|
