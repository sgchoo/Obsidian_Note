# 서로소 집합과 파티션 (Disjoint Sets and Partition)

## 서로소 집합 (Disjoint Sets)

### 정의

집합 A, B에 대해 **A ∩ B = ∅** 일 때, A와 B는 서로소 집합(disjoint set)이다.

### 특징

- **공통 원소가 없음**: 두 집합이 전혀 겹치지 않음
- **상호 배타적(Mutually Exclusive)**: 한 원소가 두 집합에 동시에 속할 수 없음

### 예시

- A = {1, 2, 3}, B = {4, 5, 6}
- A ∩ B = ∅ → A와 B는 서로소 집합

## 파티션 (Partition)

### 정의

전체집합 U 안에 n개의 집합 A₁, A₂, A₃, ..., Aₙ이 있고, U의 모든 원소들이 모두 단 하나의 Aᵢ에만 포함될 때, **{A₁, A₂, A₃, ..., Aₙ}**를 U의 파티션이라 한다.

### 파티션의 조건

#### 1. 전체 포함 (Collectively Exhaustive)

- A₁ ∪ A₂ ∪ A₃ ∪ ... ∪ Aₙ = U
- 전체집합의 모든 원소가 적어도 하나의 부분집합에 포함됨

#### 2. 상호 배타적 (Mutually Exclusive)

- Aᵢ ∩ Aⱼ = ∅ (i ≠ j인 모든 i, j에 대해)
- 서로 다른 부분집합들은 공통 원소를 갖지 않음

#### 3. 공집합 배제

- Aᵢ ≠ ∅ (모든 i에 대해)
- 파티션에 포함된 집합들은 모두 공집합이 아님

## 파티션의 성질

### 기본 성질

임의의 집합 B에 대해, A₁부터 Aₙ까지가 U의 파티션일 때:

**B = ⋃ᵢ₌₁ⁿ (Aᵢ ∩ B)**

이는 집합 B를 파티션의 각 부분과의 교집합으로 분해할 수 있음을 의미합니다.

### 파티션의 개수

- n개의 원소를 가진 집합의 파티션 개수: 벨 수(Bell Number)
- 특정 크기의 파티션 개수: 스털링 수(Stirling Number of the Second Kind)

## 예시

### 기본 예시

전체집합 U = {1, 2, 3, 4, 5, 6}에 대해:

- A₁ = {1, 2}
- A₂ = {3, 4}
- A₃ = {5, 6}

이때 {A₁, A₂, A₃}는 U의 파티션입니다.

**검증:**

- A₁ ∪ A₂ ∪ A₃ = {1, 2, 3, 4, 5, 6} = U ✓
- A₁ ∩ A₂ = ∅, A₁ ∩ A₃ = ∅, A₂ ∩ A₃ = ∅ ✓
- A₁, A₂, A₃ 모두 공집합이 아님 ✓

### 실생활 예시

- **학생 분류**: 전체 학생을 학년별로 분류
- **지역 구분**: 국가를 시/도로 분할
- **시간 분할**: 하루 24시간을 시간대별로 분할

## 응용 분야

### 수학

- 동치관계(Equivalence Relation)와 동치류(Equivalence Class)
- 확률론에서 표본공간의 분할
- 집합론에서 분류 문제

### 컴퓨터 과학

- 데이터 구조: Union-Find (Disjoint Set Union)
- 그래프 이론: 연결 성분 찾기
- 데이터베이스: 데이터 분할 및 샤딩

### 통계학

- 확률의 전확률 공식
- 베이즈 정리의 적용
- 표본 추출에서 층화 추출

## 중요한 정리

### 전확률 공식

파티션 {A₁, A₂, ..., Aₙ}에 대해: P(B) = Σᵢ₌₁ⁿ P(B|Aᵢ) × P(Aᵢ)

### 베이즈 정리

P(Aᵢ|B) = P(B|Aᵢ) × P(Aᵢ) / P(B)
