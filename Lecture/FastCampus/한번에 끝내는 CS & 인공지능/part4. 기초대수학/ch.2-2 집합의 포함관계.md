## 집합의 원소와 집합 사이의 관계

### 원소의 포함관계

- **a가 집합 A에 포함됨**: a ∈ A
- **a가 집합 A에 포함되지 않음**: a ∉ A

**예시:**

- 3 ∈ {1, 2, 3, 4, 5}
- 6 ∉ {1, 2, 3, 4, 5}

## 서로 같은 집합의 정의

집합 A의 모든 원소가 집합 B에 포함되고, 반대로 집합 B의 모든 원소가 집합 A에 포함될 때, A와 B는 **서로 같은 집합**이다.

```
A = B ⟺ (A ⊆ B) ∧ (B ⊆ A)
```

## 집합 사이의 포함관계

### 1. Subset (부분집합) - ⊆

집합 A의 **모든 원소**가 집합 B에 포함될 때, A는 B의 **부분집합**이다.

```
A ⊆ B
```

**예시:**

- {1, 2} ⊆ {1, 2, 3, 4}
- ℕ ⊆ ℤ

### 2. Superset (상위집합) - ⊇

집합 A가 집합 B의 모든 원소를 포함할 때, A는 B의 **상위집합**이다.

```
A ⊇ B (B ⊆ A와 동일)
```

**예시:**

- {1, 2, 3, 4} ⊇ {1, 2}
- ℤ ⊇ ℕ

### 3. Proper Subset (진부분집합) - ⊂

집합 A가 B의 부분집합이지만 **완전히 같지는 않을** 때, A는 B의 **진부분집합**이다.

```
A ⊂ B ⟺ (A ⊆ B) ∧ (A ≠ B)
```

**예시:**

- {1, 2} ⊂ {1, 2, 3}
- ℕ ⊂ ℤ

### 4. Proper Superset (진상위집합) - ⊃

집합 A가 B의 상위집합이지만 **완전히 같지는 않을** 때, A는 B의 **진상위집합**이다.

```
A ⊃ B ⟺ (A ⊇ B) ∧ (A ≠ B)
```

## 수 집합 사이의 포함관계

### 포함관계 다이어그램

```
ℕ ⊂ ℤ ⊂ ℚ ∪ 𝕀 ⊂ ℝ ⊂ ℂ
```

여기서:

- **ℕ**: 자연수 (Natural Numbers)
- **ℤ**: 정수 (Integers)
- **ℚ**: 유리수 (Rational Numbers)
- **𝕀**: 무리수 (Irrational Numbers)
- **ℝ**: 실수 (Real Numbers) = ℚ ∪ 𝕀
- **ℂ**: 복소수 (Complex Numbers)

### 관계 설명

- 자연수 ⊂ 정수 ⊂ 유리수 ∪ 무리수 ⊂ 실수 ⊂ 복소수
- 각 집합은 다음 집합의 진부분집합이다
