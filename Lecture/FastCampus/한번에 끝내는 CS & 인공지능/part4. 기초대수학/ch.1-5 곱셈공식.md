# 곱셈공식 유도 과정

곱셈공식은 대수학적 특징들을 체계적으로 적용하여 유도할 수 있습니다. 각 공식의 단계별 유도 과정을 살펴보겠습니다.

## 1. (a + b)² 공식

### 단계별 유도

```
(a + b)²
= (a + b)(a + b)                    [지수법칙 정의]
= a(a + b) + b(a + b)               [분배법칙 적용]
= a² + ab + ba + b²                 [분배법칙 재적용]
= a² + ab + ab + b²                 [곱셈의 교환법칙: ba = ab]
= a² + 2ab + b²                     [동류항 정리]
```

### 최종 공식

**(a + b)² = a² + 2ab + b²**

## 2. (a - b)² 공식

### 단계별 유도

```
(a - b)²
= (a - b)(a - b)                    [지수법칙 정의]
= a(a - b) - b(a - b)               [분배법칙 적용]
= a² - ab - ba + b²                 [분배법칙 재적용]
= a² - ab - ab + b²                 [곱셈의 교환법칙: ba = ab]
= a² - 2ab + b²                     [동류항 정리]
```

### 최종 공식

**(a - b)² = a² - 2ab + b²**

## 3. (a + b)(a - b) 공식

### 단계별 유도

```
(a + b)(a - b)
= a(a - b) + b(a - b)               [분배법칙 적용]
= a² - ab + ba - b²                 [분배법칙 재적용]
= a² - ab + ab - b²                 [곱셈의 교환법칙: ba = ab]
= a² - b²                           [상쇄: -ab + ab = 0]
```

### 최종 공식

**(a + b)(a - b) = a² - b²**

## 적용된 대수학적 특징

각 유도 과정에서 사용된 대수학적 특징들:

### 1. 분배법칙 (Distributive Property)

- `a(a + b) = a² + ab`
- `b(a + b) = ba + b²`

### 2. 교환법칙 (Commutative Property)

- `ba = ab` (곱셈의 순서 변경)

### 3. 결합법칙 (Associative Property)

- 동류항 정리 시 항들의 그룹핑

### 4. 항등원과 역원

- 상쇄 과정에서 `-ab + ab = 0`

## 실용적 의미

이러한 곱셈공식들은:

- **계산 효율성**: 복잡한 곱셈을 간단한 공식으로 변환
- **인수분해**: 역방향으로 사용하여 식을 간단히 표현
- **방정식 해결**: 이차방정식 등을 풀 때 핵심 도구

곱셈공식의 유도 과정은 대수학적 특징들이 어떻게 체계적으로 적용되어 유용한 도구가 되는지를 보여주는 대표적인 예시입니다.
