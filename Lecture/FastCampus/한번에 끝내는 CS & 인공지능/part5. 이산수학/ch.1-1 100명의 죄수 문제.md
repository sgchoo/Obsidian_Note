# 100명의 죄수 문제 (100 Prisoners Problem)

## 문제 설정

### 게임 규칙

- **상자**: 100개의 상자가 준비되어 있음
- **내용물**: 각 상자에는 0부터 99까지의 숫자가 하나씩 랜덤하게 들어있음
- **죄수**: 총 100명의 죄수 (0번~99번)

### 게임 진행

1. 죄수는 한 명씩 입장
2. 각 죄수는 **절반의 상자(50개)**를 열 수 있음
3. 열린 상자 중 **자신의 번호**가 들어있으면 **통과**
4. **모든 죄수가 통과**해야 최종 성공
5. **한 명이라도 실패**하면 전체 실패

## 확률 분석

### 개별 죄수의 성공 확률 (랜덤 전략)

- 한 명의 죄수가 랜덤으로 50개 상자를 선택할 때의 통과 확률
- **공식**: `99C49 / 100C50 = 1/2`
- **의미**: 100개 중 50개를 선택하므로 특정 번호가 포함될 확률은 정확히 50%

### 전체 죄수의 성공 확률 (랜덤 전략)

- 모든 죄수가 개별적으로 성공해야 하므로
- **공식**: `(1/2)^100`
- **결과**: 약 `7.89 × 10^-31` (거의 불가능)

## 확률을 높이는 전략: 순환 그래프 전략

### 핵심 아이디어

**"숫자가 시키는 대로 따라가기"**

### 전략 설명

#### 각 죄수의 행동 패턴

1. **n번 죄수**가 입장
2. **n번 상자**를 먼저 열기
3. 상자에서 나온 숫자를 **다음 상자 번호**로 사용
4. 자신의 번호가 나올 때까지 **연쇄적으로 따라가기**

#### 예시: 0번 죄수의 경우

```
0번 죄수 입장
→ 0번 상자 열기
→ 0번 상자에 2가 들어있음
→ 2번 상자 열기  
→ 2번 상자에 7이 들어있음
→ 7번 상자 열기
→ ...
→ n번 상자에 0이 들어있음 (성공!)
```

### 순환 그래프 관점

- 각 상자와 그 안의 숫자는 **방향 그래프**를 형성
- 각 노드(상자)는 정확히 하나의 나가는 간선을 가짐
- 결과적으로 여러 개의 **순환(cycle)**으로 구성됨

### 성공 조건

**가장 긴 순환의 길이가 50 이하**여야 함

#### 이유

- 각 죄수는 자신이 속한 순환을 따라가면 반드시 자신의 번호를 찾을 수 있음
- 하지만 순환의 길이가 50을 초과하면, 50번의 시도로는 자신의 번호에 도달할 수 없음
- 가장 긴 순환이 50 이하라면 **모든 죄수가 성공** 가능

### 전략의 장점

- **개별 죄수의 운에 의존하지 않음**
- **순환 구조**라는 **전체적인 배치**에만 의존
- 성공 확률이 약 **30%**로 대폭 향상 (`(1/2)^100`에서 약 `0.31`로)
