# 1. 그래프의 모델링: 지하철 노선도

**그래프(Graph)**는 **객체(Object)**와 그 객체들을 잇는 **연결(Connection)**을 모델링하는 데 사용되는 수학적 구조입니다. **지하철 노선도**는 그래프 이론을 이해하기 위한 가장 대표적이고 직관적인 예시입니다.

| 그래프 구성 요소       | 지하철 노선도에서의 대응   | 설명                    |
| :-------------- | :-------------- | :-------------------- |
| **정점 (Vertex)** | 지하철 **역**       | 객체 또는 지점을 나타냄.        |
| **간선 (Edge)**   | **역과 역 사이의 선로** | 객체들 간의 연결 또는 관계를 나타냄. |

### 1.1 서브그래프 (Subgraph)와 환승 (Transfer)

* **서브그래프 (Subgraph):** 전체 지하철 네트워크에서 **특정 하나의 호선(예: 2호선)**만을 떼어내어 볼 때, 이것을 전체 네트워크의 **서브그래프**라고 할 수 있습니다. 즉, 전체 그래프의 일부 정점과 간선으로 이루어진 그래프입니다.
* **최단 거리 문제:** 두 역 사이의 **가장 빠른 길 (최단 경로)**을 찾기 위해서는, 단순히 한 호선 내의 경로뿐만 아니라 여러 호선을 연결하는 경로를 고려해야 합니다.
* **환승 (Transfer):** 두 개 이상의 서브그래프(호선)가 만나는 **공통 정점(환승역)**을 통해 다른 노선으로 이동할 수 있습니다. 이는 복잡한 네트워크에서 경로를 탐색하는 데 결정적인 역할을 합니다.

## 2. 그래프의 표현: 인접 행렬 (Adjacency Matrix)

**인접 행렬**은 그래프의 연결 상태를 행렬 형태로 나타내는 방법이며, 컴퓨터가 그래프를 처리할 때 매우 유용합니다.

### 2.1 인접 행렬의 정의

* 그래프의 정점의 개수가 $n$개일 때, 인접 행렬 $A$는 $n \times n$ 행렬입니다.
* 행렬의 각 요소 $A_{ij}$는 정점 $i$에서 정점 $j$로 가는 **간선의 개수**를 나타냅니다.
    * 간선이 있으면 $A_{ij} = 1$ (단순 그래프의 경우)
    * 간선이 없으면 $A_{ij} = 0$

### 2.2 인접 행렬의 거듭제곱 (Matrix Powers)

인접 행렬 $A$를 **거듭제곱($A^k$)**하면, 그 행렬의 각 요소 $A^k_{ij}$는 정점 $i$에서 정점 $j$로 가는 **길이 $k$인 경로의 총 가짓수(개수)**를 의미합니다.

* **$A^2$ (인접 행렬의 제곱):** $A^2_{ij}$는 정점 $i$에서 출발하여 **정확히 두 번의 이동(간선)**을 거쳐 정점 $j$로 도착하는 경로의 총 개수를 나타냅니다.
* **$A^k$ (일반화):** 행렬을 $k$번 곱한 횟수($k$)가 곧 정점 사이를 **이동한 횟수(경로의 길이)**가 되며, 그 값은 해당 경로의 총 가짓수입니다.

$$
A^k_{ij} = \text{정점 } i \text{에서 정점 } j \text{로 가는 길이 } k \text{인 경로의 개수}
$$

**활용:** 이 성질은 그래프에서 특정 횟수만큼 이동했을 때 도달할 수 있는 모든 경로를 계산하는 데 사용됩니다.
