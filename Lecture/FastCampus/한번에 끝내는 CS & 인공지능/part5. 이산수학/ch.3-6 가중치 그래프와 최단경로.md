# 이산수학: 그래프 이론 응용 (가중치 그래프와 최단 경로)

## 1. 가중치 그래프 (Weighted Graph)

실제 세계의 많은 네트워크는 단순한 연결 여부 외에 **비용, 시간, 거리**와 같은 정량적인 값을 가집니다. 이러한 정보를 표현하기 위해 **가중치 그래프**를 사용합니다.

### 1.1 가중치 (Weight)의 정의

* **정의:** 가중치 그래프는 각 **간선($e$)**에 **가중치($w(e)$)**라는 수치적 값을 할당한 그래프입니다.
* **예시:**
    * **지하철 노선도:**
        * 간선의 가중치 = **소요 시간** (역 사이의 이동 시간) 또는 **거리**
    * **도로망:**
        * 간선의 가중치 = **통행료** 또는 **도로 길이**

### 1.2 가중치 경로 (Weighted Walk/Path)의 합산

단순 그래프에서는 경로의 **길이**를 '간선의 개수'로 측정했지만, 가중치 그래프에서는 경로의 **비용**을 간선들의 가중치를 합한 값으로 측정합니다.

* **경로의 총 가중치:** 특정 Walk 또는 Path를 구성하는 **모든 간선의 가중치를 합한 값**입니다.
    $$
    \text{총 가중치} = \sum_{\text{간선 } e \text{들}} w(e)
    $$

### 1.3 최단 경로 (Shortest Path) 문제

**최단 경로 문제**는 두 정점 $A$와 $B$ 사이를 잇는 모든 가능한 Path 중에서 **총 가중치가 가장 작은 Path**를 찾는 문제입니다.

* **탐색 원리:**
    1.  $A$에서 $B$로 가는 가능한 모든 Walk (또는 Path)를 찾습니다.
    2.  각 Walk마다 **간선의 가중치를 누적**하여 총 가중치를 계산합니다.
    3.  이 누적된 가중치들을 **비교**하여, 가장 작은 값을 가진 경로를 **최단 경로**로 결정합니다.

### 1.4 지하철 예시 (환승 비용)

지하철 노선도에서 최단 경로를 구할 때 가중치를 활용하는 것은 현실적인 문제를 해결하는 중요한 방법입니다.

* **일반 간선:** 역과 역 사이의 이동 시간에 해당하는 가중치를 부여합니다.
* **환승:** **환승역**에서 다른 노선으로 갈아탈 때 발생하는 추가적인 시간(예: 긴 통로 이동, 열차 대기 시간)을 별도의 **가중치**로 설정하여 더해줍니다.
    * **정확한 모델링:** 환승에 대한 가중치(환승 비용)를 경로의 총 가중치에 포함함으로써, 단순히 간선 수만 적은 경로가 아닌, **실제 소요 시간이 가장 짧은 최단 경로**를 구할 수 있게 됩니다.

**활용 알고리즘:** 이 최단 경로를 효율적으로 찾기 위해 **다익스트라(Dijkstra) 알고리즘**이나 **벨만-포드(Bellman-Ford) 알고리즘** 등의 전문적인 알고리즘이 사용됩니다.
