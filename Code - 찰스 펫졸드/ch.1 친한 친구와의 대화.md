# Code - Chapter 1: 친한 친구와의 대화

## 📖 개요

찰스 펫졸드의 "Code"는 컴퓨터의 작동 원리를 가장 기초부터 설명하는 책으로, Chapter 1에서는 **부호(Code)**의 개념과 정보 전달의 기본 원리를 소개합니다.

## 🔑 핵심 개념: 부호(Code)란?

### 부호의 정의

- **부호(Code)**: 사람 사이에, 사람과 컴퓨터 간에, 컴퓨터끼리 정보를 전달하는 체계
- 의사소통을 위한 약속된 신호 체계

### 부호의 특성

- 어떤 부호가 다른 부호로 완전히 처리되지 않더라도, **적절히 사용될 수 있다면 유용**하다
- 상황에 따라 최적의 부호 체계가 달라질 수 있음

## 💡 손전등 통신: 디지털 통신의 시작

### 상황 설정

두 친구가 멀리 떨어진 집에서 밤에 창문을 통해 소통해야 하는 상황

### 기본 신호 체계

- **손전등 1번 깜빡임** = "예"
- **손전등 2번 깜빡임** = "아니오"

### 발전된 신호 체계

- 더 복잡한 메시지 전달을 위해 체계적인 부호 개발 필요
- **On/Off**, **있음/없음**의 단순한 신호로도 복잡한 정보 전달 가능

## 🔗 모스 부호와의 연관성

### 모스 부호의 원리

- **점(·)과 선(-)의 조합**으로 모든 문자 표현
- 멀리 떨어진 상태에서 말과 글보다 효율적인 통신 수단
- **두 가지 기본 요소**만으로 무한한 정보 표현 가능

### 디지털 세계로의 확장

```
모스 부호: 점(·) + 선(-)
↓
디지털: 0 + 1
↓
컴퓨터: Off + On
```

## 💻 컴퓨터에서의 부호 활용

### 다양한 정보 처리

컴퓨터는 다음과 같은 모든 형태의 정보를 부호로 처리:

- 문자 (Text)
- 숫자 (Numbers)
- 소리 (Sound)
- 음악 (Music)
- 그림 (Images)
- 영화 (Movies)
- 명령어 (Commands)

### 이진 부호의 힘

**두 가지 다른 것들(0과 1)이 적절히 조합되어 모든 형태의 정보로 전달할 수 있다**
=> 즉 컴퓨터에서 사용하는 이진 코드의 기본원리를 설명하고 있다.
