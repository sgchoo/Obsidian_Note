# Code - Chapter 3: 점자와 이진 부호

## 📖 개요

Chapter 3에서는 브레일 점자 시스템을 이진 부호의 관점에서 분석하고, 부호 체계에서 발생할 수 있는 오류와 이를 해결하기 위한 방법들을 다룹니다.

## 🔤 브레일: 실제 세계의 이진 시스템

### 이진 표현의 기초

**점자는 튀어나오거나, 평평하거나로 이진 부호로 표현 가능하다**

```
브레일 점의 상태:
튀어나옴 (Raised) = 1
평평함 (Flat)     = 0

예시: 문자 'A'
[●] [ ]     →  1 0
[ ] [ ]     →  0 0  
[ ] [ ]     →  0 0
= 100000₂
```

### 브레일과 이진 코드의 직접적 대응

- 6개 점 = 6비트
- 각 점의 상태 = 1비트 정보
- 총 2⁶ = 64가지 조합 가능

## ⚠️ 부호 시스템의 오류 문제

### 오류의 종류

**점과 같은 부호에서는 오류가 발생하기 쉬운데, 인코딩 오류, 디코딩 오류, 전송 오류 등이 있다**

#### 1. 인코딩 오류 (Encoding Error)

```
의도한 문자: 'A' (100000)
잘못 인코딩: 'C' (110000)
```

- 원본 정보를 부호로 변환할 때 발생
- 사람의 실수나 시스템 오류

#### 2. 디코딩 오류 (Decoding Error)

```
받은 부호: 100000 ('A')
잘못 해석: 'B'로 읽음
```

- 부호를 원본 정보로 해석할 때 발생
- 읽는 사람의 실수나 해석 오류

#### 3. 전송 오류 (Transmission Error)

```
보낸 부호: 100000 ('A')
전송 중:    점이 손상됨
받은 부호: 110000 ('C')
```

- 부호가 전달되는 과정에서 발생
- 물리적 손상, 노이즈, 매체 결함
