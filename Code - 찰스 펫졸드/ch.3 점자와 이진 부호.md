# Code - Chapter 3: 점자와 이진 부호

## 📖 개요

Chapter 3에서는 브레일 점자의 체계적 패턴을 분석하면서 이진수 체계의 기초를 본격적으로 다루고, 전기 회로의 기본 원리를 통해 디지털 시스템의 물리적 기반을 설명합니다.

## ⚡ 전기 회로: 디지털의 물리적 기초

### 기본 회로 원리

**건전지와 전구를 연결하는 전선이 끊어져 있으면, 전구에 불이 들어오지 않고, 전선이 연결되면 전구에 불이 들어온다**

```
끊어진 회로 (Open Circuit):
건전지 ─────┊─────── 전구 (꺼짐)
        (끊어진 부분)

연결된 회로 (Closed Circuit):  
건전지 ─────────────── 전구 (켜짐)
```

### 네트워크와의 연관성

**노드와 노드끼리 통신 회로를 통해 서로 연결된다**

- 전기 회로의 연결/차단 = 네트워크의 연결/차단
- 전구의 On/Off = 디지털 신호의 1/0
- 물리적 연결이 논리적 정보 전달의 기반

## 🔋 전원 공급 방식과 시스템 확장성

### 직렬 연결 (Series Connection)

```
건전지1 ─ 건전지2 ─ 전구
```

**특징:**

- 전압 증가 (1.5V + 1.5V = 3V)
- 하나가 고장나면 전체 시스템 정지
- 높은 성능, 높은 위험성

### 병렬 연결 (Parallel Connection)

```
건전지1 ─┬─ 전구
건전지2 ─┘
```

**특징:**

- 전류 용량 증가
- 하나가 고장나도 다른 것으로 동작 가능
- 안정성과 내결함성

### 현대 시스템과의 연관성

**서버의 확장성(아웃/업 스케일), DB 전략(마스터/슬레이브, 샤딩/파티셔닝)과 같음**

|전기 회로|컴퓨터 시스템|특징|
|---|---|---|
|직렬 연결|Scale-Up (수직 확장)|성능 향상, 단일 장애점|
|병렬 연결|Scale-Out (수평 확장)|안정성, 분산 처리|
||Master-Slave DB|읽기 분산, 내결함성|
||Sharding/Partitioning|데이터 분산, 병렬 처리|

## 📡 전송 매체와 네트워크 성능

### 전선 굵기와 전송 용량

**전선의 굵기가 굵어짐에 따라 전선을 따라 흐를 수 있는 가능성이 있는 전자의 수도 증가한다**

### 네트워크 대역폭과의 연관성

**네트워크 케이블의 굵기에 따라 네트워크 대역폭이 결정됨**

```
물리적 매체     →    네트워크 성능
얇은 전선      →    낮은 대역폭
굵은 전선      →    높은 대역폭
광섬유        →    초고속 대역폭
```

### 거리와 지연시간

**케이블이 길어질수록 지연시간이 길어짐**

- **물리적 한계**: 빛의 속도도 유한함
- **신호 감쇠**: 거리에 따른 신호 약화
- **네트워크 지연**: Latency = 거리 ÷ 신호 속도

### 컴퓨터 내부 버스

**컴퓨터 내부 버스도 이와 같음**

```
CPU ←─버스─→ 메모리
 ↕
버스 폭 = 동시 전송 가능한 비트 수
버스 속도 = 클럭 주파수
```

## 🔄 스위치: 제어의 핵심

### 기본 스위치 개념

- **Open**: 회로 차단 (0, False, Off)
- **Closed**: 회로 연결 (1, True, On)
- 모든 디지털 논리의 기본 단위

### 네트워크 장비와의 연관성

**스위치, 라우터, 게이트웨이 등등**

|전기 장치|네트워크 장비|기능|
|---|---|---|
|스위치|Network Switch|신호 연결/차단|
|복합 스위치|Router|경로 선택 및 제어|
|변환 스위치|Gateway|프로토콜 변환|
