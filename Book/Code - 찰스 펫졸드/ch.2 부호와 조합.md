# Code - Chapter 2: 부호와 조합

## 📖 개요

Chapter 1에서 손전등을 이용한 기본적인 부호 개념을 소개했다면, Chapter 2에서는 **브레일 점자 시스템**을 통해 부호의 조합론적 원리와 수학적 기초를 체계적으로 설명합니다.

## 🔤 브레일 점자: 실제 세계의 이진 시스템

### 브레일의 구조

- **6개의 점**으로 구성된 셀 (3×2 배열)
- 각 점은 **볼록하게 튀어나오거나** 또는 **평평한 상태**
- 본질적으로 **6비트 이진 시스템**

```
브레일 셀 구조:
[1] [4]
[2] [5]
[3] [6]

각 점: 볼록(1) 또는 평평(0)
```

### 브레일과 이진 코드의 관계

- 브레일의 각 점 = 컴퓨터의 1비트
- 점이 튀어나옴 = 1 (On)
- 점이 평평함 = 0 (Off)

## 🔢 조합론의 수학적 원리

### 기본 공식

**표현할 수 있는 부호의 수는 전달된 점과 선의 수를 2의 승수로 사용하여 알 수 있다.**

```
n개의 이진 선택 → 2^n개의 조합 가능
```

### 브레일 적용 예시

- **6개의 점** → 2^6 = **64가지 조합**
- 이는 다음을 표현하기에 충분:
    - 알파벳 26개 (A-Z)
    - 숫자 10개 (0-9)
    - 구두점 및 특수문자
    - 기타 기호들
