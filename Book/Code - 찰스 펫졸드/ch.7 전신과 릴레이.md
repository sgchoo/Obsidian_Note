# Code - Chapter 7: 전신과 릴레이

## 📖 개요

Chapter 7에서는 전신 시스템의 자동화와 릴레이를 통한 장거리 통신 방식을 다룹니다. 이는 현대 네트워크의 홉(Hop) 방식과 라우팅의 기초가 되는 중요한 개념들을 포함합니다.

## 📡 자동화된 통신 시스템

### 수동에서 자동으로의 전환

초기 전신 시스템은 사람이 직접 모스 부호를 송수신했지만, 기술 발전으로 자동화가 가능해졌습니다.

**자동으로 데이터를 수신하고, 송신하는 장치가 마련됨**

```
수동 시스템:
사람 → 전신기 → 모스 부호 → 전신기 → 사람
 ↑      (수동)              (수동)     ↑
송신자                              수신자

자동 시스템:  
데이터 → 자동 송신기 → 신호 → 자동 수신기 → 데이터
       (기계적 처리)        (기계적 해석)
```

### 자동화의 장점

- **속도 향상**: 인간보다 빠른 신호 처리
- **정확성 증대**: 인적 오류 감소
- **연속 운영**: 24시간 무중단 통신 가능
- **대용량 처리**: 많은 양의 데이터 동시 처리

## 📏 거리와 신호 품질의 관계

### 장거리 통신의 가능성과 한계

**시야 범위 밖까지 데이터를 송수신할 수 있지만, 거리가 멀수록 노이즈 발생**

```
신호 강도와 거리의 관계:

송신지     100km      200km      300km     수신지
  |━━━━━━━|━━━━━━━|━━━━━━━|━━━━━━━|
강함       약함      매우약함    거의없음    

노이즈 레벨: ~~~~~~~~~~~~~~~~~~~~~~~~
             (일정한 배경 노이즈)
```

### 신호 감쇠의 원인

1. **저항에 의한 손실**: 전선의 저항으로 인한 전력 손실
2. **유도 노이즈**: 주변 전자기장의 간섭
3. **환경적 요인**: 날씨, 온도 변화 등
4. **거리 제곱 법칙**: 신호 강도는 거리의 제곱에 반비례

## 🔄 릴레이 방식의 도입

### 릴레이 시스템의 원리

**전달하고 싶은 목적지까지 전파하는 릴레이 방식을 채택함**

```
직접 전송 (문제):
송신지 ─────────────────────── 수신지
        (신호 약화, 노이즈 증가)

릴레이 전송 (해결):
송신지 ── 릴레이1 ── 릴레이2 ── 릴레이3 ── 수신지
         (신호재생) (신호재생) (신호재생)
```

### 릴레이의 동작 방식

1. **신호 수신**: 약해진 신호를 받음
2. **신호 증폭**: 원래 강도로 복원
3. **신호 재전송**: 다음 중계점으로 전달
4. **오류 수정**: 노이즈 제거 및 신호 정리

## 🌐 현대 네트워크의 홉 방식

### 홉(Hop) 개념의 탄생

**한 노드에서 다음 노드까지 건너뛰어서 목적지까지 도달하는 홉 방식의 토대**

```
네트워크 홉:
컴퓨터A → 라우터1 → 라우터2 → 라우터3 → 컴퓨터B
        (1홉)     (2홉)     (3홉)
```

### 현대 인터넷에서의 적용

#### 1. IP 라우팅

bash

```bash
# traceroute 명령어로 홉 경로 확인
$ traceroute google.com
1  192.168.1.1     1ms   (홈 라우터)
2  10.0.0.1       5ms   (ISP 게이트웨이)  
3  203.241.132.1  15ms  (지역 ISP)
4  8.8.8.8        25ms  (Google DNS)
```

#### 2. TTL (Time To Live)

```
패킷 헤더의 TTL 필드:
초기값: 64
홉1: TTL=63 (1 감소)
홉2: TTL=62 (1 감소)  
홉3: TTL=61 (1 감소)
...
TTL=0 도달 시 패킷 폐기 (무한 루프 방지)
```

#### 3. 다중 경로 라우팅

```
경로 A: 서울 → 부산 → 일본 → 미국 (지연: 200ms)
경로 B: 서울 → 중국 → 미국       (지연: 180ms)  
경로 C: 서울 → 러시아 → 미국     (지연: 250ms)

동적 라우팅: 실시간으로 최적 경로 선택
```

## 🔧 릴레이 기술의 발전

### 물리적 릴레이에서 논리적 릴레이로

#### 1. 전기기계식 릴레이 (19세기)

```
전자석 기반 스위치:
입력 신호 → 전자석 활성화 → 접점 연결 → 출력 신호
```

#### 2. 전자 릴레이 (20세기 중반)

```
진공관/트랜지스터 기반:
입력 신호 → 증폭 회로 → 출력 신호 (기계적 부품 없음)
```

#### 3. 디지털 릴레이 (현대)

```
소프트웨어 기반 라우터:
입력 패킷 → 라우팅 테이블 조회 → 최적 경로 결정 → 출력 포트
```

## 🌍 현대 통신 시스템에서의 응용

### 1. 셀룰러 네트워크

```
기지국 릴레이 시스템:
휴대폰 → 기지국1 → 기지국2 → ... → 목적지 휴대폰
        (핸드오버)  (핸드오버)
```

### 2. 위성 통신

```
지상 → 위성1 → 위성2 → 위성3 → 지상
     (업링크) (위성간) (위성간) (다운링크)
```

### 3. 광섬유 네트워크

```
신호 증폭기 (EDFA: Erbium Doped Fiber Amplifier):
광신호 ── 증폭기1 ── 증폭기2 ── 증폭기3 ── 광신호
        (50km마다)  (50km마다)  (50km마다)
```

### 4. CDN (Content Delivery Network)

```
원본 서버 → 엣지 서버1 → 엣지 서버2 → 사용자
           (지역별)     (지역별)
```

## ⚡ 성능 최적화 전략

### 1. 홉 수 최소화

```
직접 연결: A → B (1홉, 빠름)
우회 연결: A → C → D → B (3홉, 느림)

최적화: 최단 경로 알고리즘 사용
```

### 2. 로드 밸런싱

```
부하 분산:
클라이언트 → 로드밸런서 → 서버1, 서버2, 서버3
                        (트래픽 분산)
```

### 3. 캐싱 전략

```
다단계 캐싱:
요청 → L1 캐시 → L2 캐시 → 원본 데이터
     (빠름)    (중간)    (느림)
```

## 🔍 오류 처리와 복구

### 1. 경로 중복성 (Redundancy)

```
주 경로: A → B → C → D
백업 경로: A → E → F → D
        (주 경로 장애 시 자동 전환)
```

### 2. 체크포인트와 복구

```
송신 → 체크포인트1 → 체크포인트2 → 수신
      (상태 저장)    (상태 저장)
      
장애 발생 시: 마지막 체크포인트부터 재시작
```

### 3. 적응적 라우팅

python

```python
# 네트워크 상태 모니터링
def select_best_path(destination):
    paths = get_available_paths(destination)
    return min(paths, key=lambda p: p.latency + p.loss_rate)
```
