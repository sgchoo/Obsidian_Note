# 제16장: 그렇다면 뺄셈은 어떨까요
## 1. 뺄셈의 기본 원리: 자리 빌림 (Borrows)

- **인간의 방식**: 우리가 10진수 뺄셈을 할 때, 윗자리에서 수를 빌려오는 **'자리 빌림(borrow)'** 개념을 사용합니다.
- **컴퓨터의 문제**: 이진수 뺄셈기도 '자리 빌림' 로직을 포함하여 만들 수 있습니다. 하지만 이는 12장에서 이미 만든 **가산기(Adder, 덧셈 회로)와는 별개의 복잡한 회로**를 추가로 설계해야 한다는 것을 의미합니다.
- **해결 과제**: 하드웨어를 더 효율적으로 사용하기 위해, **이미 만들어 둔 덧셈 회로를 그대로 사용하여 뺄셈을 수행할 방법**은 없을까?

## 2. 뺄셈을 덧셈으로 바꾸는 마법: '보수(Complement)'

- **아이디어**: 어떤 수에서 다른 수를 빼는 것은, 그 수의 **'보수(음수처럼 동작하는 수)'**를 더하는 것과 결과가 같습니다. `A - B`는 `A + (-B)`와 같습니다.
- **10진수에서의 보수**:
    - **9의 보수**: 각 자릿수를 9에서 빼서 만듭니다. (예: 123의 9의 보수는 876)
    - **10의 보수**: 9의 보수에 1을 더해서 만듭니다. 이것이 10진수 음수를 표현하는 효과적인 방법입니다.
- **보수를 이용한 뺄셈**: `A - B`를 계산할 때, `A + (B의 10의 보수)`를 계산한 뒤, 가장 높은 자리 올림수를 버리면 동일한 결과를 얻을 수 있습니다. 이로써 뺄셈이 덧셈으로 바뀌었습니다.

## 3. 컴퓨터의 방식: 2의 보수 (Two's Complement)

- **2진수에서의 보수**: 컴퓨터는 2진수를 사용하므로, 10진수 보수와 동일한 원리를 2진수에 적용합니다.
    - **1의 보수**: 모든 비트(0과 1)를 뒤집습니다. (NOT 게이트로 간단히 구현 가능)
    - **2의 보수**: **1의 보수를 취한 후, 1을 더합니다.** 이것이 현대 컴퓨터가 음수를 표현하고 뺄셈을 처리하는 표준 방식입니다.
- **장점**: 2의 보수 체계를 사용하면 덧셈 회로(가산기) 하나만으로 **덧셈과 뺄셈을 모두 처리**할 수 있어 하드웨어가 매우 단순하고 효율적이 됩니다.

## 4. 양수와 음수의 구분: 부호 비트 (Sign Bit)

- **문제**: `1011` 같은 이진수가 양수 11인지, 아니면 어떤 음수를 2의 보수로 표현한 것인지 컴퓨터는 어떻게 알 수 있을까요?
- **해결책**: 숫자를 표현하는 비트들 중 **가장 왼쪽의 비트(MSB, Most Significant Bit)**를 **'부호 비트'**로 사용하기로 약속합니다.
    - **`0`이면 양수**
    - **`1`이면 음수**
- **예시 (8비트 기준)**:
    - `0000 0111` → 부호 비트가 0이므로 양수, 값은 7입니다.
    - `1111 1001` → 부호 비트가 1이므로 음수, 이 값은 -7을 2의 보수로 표현한 것입니다.

### ✔️ 핵심 요약 및 개념 연결

이 챕터는 **하드웨어의 효율성**이라는 공학적 목표를 달성하기 위해 어떻게 뺄셈이라는 연산을 덧셈으로 변환하는지를 보여줍니다. 12장에서 만든 가산기를 재활용하기 위해 **'보수'**라는 수학적 개념을 도입하고, 컴퓨터 환경(2진수)에 맞게 이를 **'2의 보수'**로 변환하여 적용합니다. 마지막으로, 양수와 음수를 모두 다루기 위해 **'부호 비트'**라는 규칙을 만들어 현대 컴퓨터의 정수 연산 체계가 완성되는 과정을 설명합니다.
