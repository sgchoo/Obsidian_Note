# Chapter 11: 비트, 비트, 비트 (Bits, Bits, Bits)

## 📌 핵심 개념

### 비트의 본질
- **비트(Bit)**: 아주 작은 정보를 전달하는 기본 단위
- **Binary digit**의 줄임말로, 0 또는 1의 값을 가짐

### 정보 표현의 원리
- 어떠한 정보라도 **2개 혹은 그 이상의 가능성** 중 하나를 선택하는 것으로 단순화시킬 수 있다면, **비트를 이용해 표현할 수 있다**
- 모든 복잡한 정보는 결국 이진 선택의 연속으로 분해 가능

### UPC(Universal Product Code)
- **UPC(세계 상품 부호)도 이진 부호**다
- 바코드의 검은 줄과 흰 줄이 비트 정보를 담고 있음
- 상품 식별을 위한 디지털 정보의 물리적 구현

### 오류 검출 메커니즘
#### 패리티 비트 (Parity Bit)
- **보호 패턴**으로 패리티 비트(짝수, 홀수)가 있다
- **오류 및 일치성 확인** 역할 수행
- 데이터 전송이나 저장 과정에서 발생할 수 있는 오류 감지

#### 모듈로 점검
- **모듈로 점검 문자** 역할을 함
- 추가적인 데이터 무결성 보장

## 🔍 추가 설명

### 비트의 정보량
```
1비트 = 2가지 선택 (0 또는 1)
2비트 = 4가지 선택 (00, 01, 10, 11)
3비트 = 8가지 선택 (000, 001, 010, 011, 100, 101, 110, 111)
n비트 = 2^n 가지 선택
```

### 정보 이진화의 예시
```
예/아니오 질문 → 1비트 (0 또는 1)
네 방향 (동서남북) → 2비트 (00, 01, 10, 11)
알파벳 대문자 (26개) → 5비트 (2^5 = 32 > 26)
ASCII 문자 → 7비트 (2^7 = 128개 문자)
```

### UPC 바코드 구조
```
UPC-A 바코드 구조:
- 시작 패턴: 101
- 제조업체 코드: 6자리
- 상품 코드: 5자리  
- 체크 디지트: 1자리
- 중간 패턴: 01010
- 우측 데이터: 6자리
- 종료 패턴: 101
```

### 패리티 비트 동작 원리
#### 짝수 패리티 (Even Parity)
```
데이터: 1011 (1의 개수: 3개 - 홀수)
패리티 비트: 1 (전체를 짝수로 만들기 위해)
전송 데이터: 10111
```

#### 홀수 패리티 (Odd Parity)
```
데이터: 1011 (1의 개수: 3개 - 홀수)
패리티 비트: 0 (홀수 유지)
전송 데이터: 10110
```

### 오류 검출 예시
```
원본: 10111 (짝수 패리티)
수신: 10011 (1의 개수: 3개 - 홀수)
→ 오류 발생 감지!
```

## 💡 실제 응용

### 일상 속 비트 활용
- **QR 코드**: 흑백 패턴으로 정보 저장
- **CD/DVD**: 반사도 차이로 0과 1 구분
- **메모리 카드**: 전하 상태로 비트 저장
- **통신**: 전압 높낮이로 디지털 신호 전송

### 현대적 오류 검출 방법
- **체크섬(Checksum)**: 데이터 합계를 이용한 검증
- **CRC(Cyclic Redundancy Check)**: 다항식을 이용한 고급 검증
- **해밍 코드**: 오류 위치 특정 및 자동 수정
- **Reed-Solomon**: CD, DVD에서 사용하는 강력한 오류 정정

### 정보 압축과 비트
- **허프만 코딩**: 자주 사용되는 문자에 적은 비트 할당
- **런 길이 인코딩**: 연속된 같은 값을 압축
- **JPEG, MP3**: 손실 압축으로 용량 최적화

## 📝 핵심 포인트
1. **비트는 정보의 가장 작은 단위**로, 모든 디지털 정보의 기초
2. **이진 선택의 연속**으로 복잡한 정보도 표현 가능
3. **오류 검출 메커니즘**은 디지털 시스템의 신뢰성 확보에 필수적
4. **UPC 같은 실생활 시스템**도 근본적으로는 비트 기반의 이진 부호
5. 패리티 비트와 모듈로 점검으로 **데이터 무결성** 보장
